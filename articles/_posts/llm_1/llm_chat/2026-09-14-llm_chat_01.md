## {{ page.section_title }}

### このチャプターについて

前のチャプターでは、ターミナルから Ruby で LLM を呼び出しました。このチャプターでは Sinatra を使って、ブラウザで使えるチャットアプリを作ります。

Ollama は起動したままにしておいてください。

### ディレクトリとファイルを作る

```bash
$ mkdir llm_chat
$ cd llm_chat
llm_chat $ mkdir views
llm_chat $ touch app.rb views/index.erb
```

### gem をインストールする

```bash
llm_chat $ gem install sinatra rackup puma
```

Sinatra 4 からは、サーバーを起動するために `rackup` と `puma` も必要です。

### アプリ本体

app.rb

```ruby
require "sinatra"
require "net/http"
require "json"

OLLAMA_URI = URI("http://localhost:11434/api/chat")
MODEL = "qwen2.5:3b"

# LLMに会話を送り、回答の文章を返す
def ask(messages)
  body = { model: MODEL, messages: messages, stream: false }
  res = Net::HTTP.post(OLLAMA_URI, body.to_json, "Content-Type" => "application/json")
  JSON.parse(res.body)["message"]["content"]
end

get "/" do
  erb :index
end

post "/chat" do
  @question = params[:question]
  @answer = ask([{ role: "user", content: @question }])
  erb :index
end
```

`ask` メソッドの中身は、前のチャプターの main.rb とほぼ同じです。

### 画面

views/index.erb

```erb
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>ローカルLLMチャット</title>
</head>
<body>
  <h1>ローカルLLMチャット</h1>
  <form action="/chat" method="post">
    <textarea name="question" rows="3" cols="50"></textarea>
    <button type="submit">送信</button>
  </form>
  <% if @answer %>
    <p><strong>あなた：</strong><%= Rack::Utils.escape_html(@question) %></p>
    <p><strong>AI：</strong><%= Rack::Utils.escape_html(@answer).gsub("\n", "<br>") %></p>
  <% end %>
</body>
</html>
```

LLM の回答をそのまま HTML に入れると、回答の中に `<script>` などが含まれていた場合に危険なので、`Rack::Utils.escape_html` でエスケープしてから表示します。

### ファイルの実行

bash
```
llm_chat $ ruby app.rb
```

ブラウザで `http://localhost:4567` を開きます。

### 結果

フォームに質問を入れて送信すると、LLM の回答が表示される。
