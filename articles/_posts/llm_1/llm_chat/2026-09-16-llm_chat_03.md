### キャラクターを決める

前のチャプターで使った system プロンプトを、チャットアプリにも入れます。system プロンプトは画面には表示しないので、`HISTORY` には入れず、送るときだけ先頭に付けます。

app.rb

```ruby
(略)
# 会話の履歴
HISTORY = []

# AIのキャラクター設定
SYSTEM_PROMPT = "あなたはプログラミングスクールのアシスタントです。初心者にもわかるように、短く答えてください。"

(略)

post "/chat" do
  HISTORY << { role: "user", content: params[:question] }
  answer = ask([{ role: "system", content: SYSTEM_PROMPT }] + HISTORY)
  HISTORY << { role: "assistant", content: answer }
  redirect "/"
end
```

### リセットボタンを作る

app.rb

```ruby
(略)
post "/chat" do
(略)
end

post "/reset" do
  HISTORY.clear
  redirect "/"
end
```

views/index.erb

```erb
(略)
  <form action="/chat" method="post">
    <textarea name="question" rows="3" cols="50"></textarea>
    <button type="submit">送信</button>
  </form>
  <form action="/reset" method="post">
    <button type="submit">会話をリセット</button>
  </form>
</body>
</html>
```

### ファイルの実行

bash
```
llm_chat $ ruby app.rb
```

### 結果

AI が設定したキャラクターで答え、リセットボタンで会話が最初からになる。

### ここまでのコード

app.rb

```ruby
require "sinatra"
require "net/http"
require "json"

OLLAMA_URI = URI("http://localhost:11434/api/chat")
MODEL = "qwen2.5:3b"

# 会話の履歴
HISTORY = []

# AIのキャラクター設定
SYSTEM_PROMPT = "あなたはプログラミングスクールのアシスタントです。初心者にもわかるように、短く答えてください。"

# LLMに会話を送り、回答の文章を返す
def ask(messages)
  body = { model: MODEL, messages: messages, stream: false }
  res = Net::HTTP.post(OLLAMA_URI, body.to_json, "Content-Type" => "application/json")
  JSON.parse(res.body)["message"]["content"]
end

get "/" do
  erb :index
end

post "/chat" do
  HISTORY << { role: "user", content: params[:question] }
  answer = ask([{ role: "system", content: SYSTEM_PROMPT }] + HISTORY)
  HISTORY << { role: "assistant", content: answer }
  redirect "/"
end

post "/reset" do
  HISTORY.clear
  redirect "/"
end
```

views/index.erb

```erb
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>ローカルLLMチャット</title>
</head>
<body>
  <h1>ローカルLLMチャット</h1>
  <% HISTORY.each do |message| %>
    <p>
      <strong><%= message[:role] == "user" ? "あなた" : "AI" %>：</strong>
      <%= Rack::Utils.escape_html(message[:content]).gsub("\n", "<br>") %>
    </p>
  <% end %>
  <form action="/chat" method="post">
    <textarea name="question" rows="3" cols="50"></textarea>
    <button type="submit">送信</button>
  </form>
  <form action="/reset" method="post">
    <button type="submit">会話をリセット</button>
  </form>
</body>
</html>
```

#### *ここで試したいこと

- `SYSTEM_PROMPT` を変えて、自分だけのキャラクターを作る。
- `MODEL` を別のモデルに変えて、同じキャラクター設定でも話し方が変わるか比べる。
- 画面に使っているモデル名を表示してみる。
