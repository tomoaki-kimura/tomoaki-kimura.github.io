### このチャプターについて

前のチャプター「WASMビルド」では、1ファイルの簡単なアプリをブラウザで動かす手順を学びました。このチャプターでは、Ruby2D(1)で作ったヘビゲームを同じ手順でWASM化し、実際にブラウザで公開するところまでやってみます。

ヘビゲームは `main.rb` 1ファイルで完結しているので、前チャプターの手順がそのまま使えます。

### プロジェクトを開く

Ruby2D(1)ヘビゲームチャプターで作った `ruby2d/hebi` ディレクトリを使います。

```bash
$ cd ruby2d/hebi
ruby2d/hebi $ ls
main.rb
```

### Emscripten SDK を有効化する

新しいターミナルを開いた場合は、emsdk を有効化しておきます。

```bash
$ cd emsdk
emsdk $ source ./emsdk_env.sh
$ cd ~/ruby2d/hebi
```

すでに有効化済みのターミナルであればこの手順は不要です。

#### *ここで試したいこと

- `emcc -v` を実行して、Emscripten が有効化されていることを確認しよう。
