## {{ page.section_title }}

### ビルドする

```bash
ruby2d/hebi $ ruby2d build --web main.rb
```

前チャプターと同じコマンドです。`main.rb` が1ファイルで完結しているため、そのまま実行できます。

### 生成されたファイルを確認する

```bash
ruby2d/hebi $ ls build/web
main.data  main.html  main.js  main.wasm
```

### ローカルサーバーで動かす

```bash
ruby2d/hebi $ ruby2d launch --web main.rb
Serving at http://localhost:8080/main.html
```

ブラウザで `http://localhost:8080/main.html` を開いて、ヘビゲームが動くことを確認しましょう。キーボードの矢印キーで操作できます。

確認が終わったら `Ctrl + C` でサーバーを止めます。

#### *ここで試したいこと

- `ruby2d build --web --single-file main.rb` を実行して、`main.html` 1ファイルにまとまることを確認しよう。
