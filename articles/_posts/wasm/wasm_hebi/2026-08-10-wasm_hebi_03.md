### GitHub Pages に公開する

`build/web` の中身（`main.html`・`main.js`・`main.wasm`・`main.data`）は静的ファイルなので、GitHub Pages にそのまま置くだけで公開できます。

公開用のリポジトリを用意して、`build/web` の中身をプッシュしましょう。

```bash
ruby2d/hebi $ cd build/web
build/web $ git init
build/web $ git add .
build/web $ git commit -m "ヘビゲーム WASM 公開"
build/web $ git branch -M main
build/web $ git remote add origin https://github.com/ユーザー名/リポジトリ名.git
build/web $ git push -u origin main
```

GitHub のリポジトリ設定から GitHub Pages を有効にすれば、`https://ユーザー名.github.io/リポジトリ名/main.html` でアクセスできます。
