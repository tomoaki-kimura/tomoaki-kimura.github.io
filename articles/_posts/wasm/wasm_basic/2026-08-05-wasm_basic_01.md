## {{ page.section_title }}

### このチャプターについて

Ruby2D はバージョン1.0.0から、同じRubyのコードをブラウザ上で動かす「WebAssembly（WASM）」ビルドに対応しました。このチャプターでは、Ruby2D(1)基礎チャプターで作ったアプリを、ブラウザで動く形に書き出します。

現時点ではmacOS環境での手順のみを扱います。

### Emscripten SDK をダウンロードする

Emscripten（emsdk）は、Cのコードや、Ruby2Dが使っているネイティブライブラリをWebAssemblyに変換するためのツールチェインです。好きな場所にディレクトリを作ってダウンロードします。

```bash
$ git clone https://github.com/emscripten-core/emsdk.git
$ cd emsdk
```

### インストールして有効化する

```bash
emsdk $ ./emsdk install latest
emsdk $ ./emsdk activate latest
```

### 使えるようにする

ダウンロードしただけでは、ターミナルはまだ `emcc`（Emscriptenのコンパイラ）の場所を知りません。以下を実行して、このターミナルで使えるようにします。

```bash
emsdk $ source ./emsdk_env.sh
```

`source` はターミナルを閉じるたびに効果が切れるので、新しいターミナルを開いたときはもう一度実行します。

### 確認する

```bash
$ emcc -v
```

`emcc (Emscripten gcc/clang-like replacement...)` から始まるバージョン情報が表示されればOKです。

#### *ここで試したいこと

- `./emsdk list` を実行して、インストールできるバージョンの一覧を見てみよう。
