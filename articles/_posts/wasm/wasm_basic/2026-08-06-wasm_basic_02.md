## {{ page.section_title }}

### Ruby2D(1)基礎のプロジェクトを開く

Ruby2D(1)基礎チャプターで作った `ruby2d/basic` ディレクトリを使います。

```bash
$ cd ruby2d/basic
ruby2d/basic $ ls
main.rb
```

`main.rb` の中身は、円が跳ね返りながら不規則に色が変わるプログラムでした。

### ビルドする

Emscriptenを有効化したターミナルで、以下を実行します（前セクションで `source ./emsdk_env.sh` したターミナルをそのまま使うか、新しいターミナルなら再度 `source` してください）。

```bash
ruby2d/basic $ ruby2d build --web main.rb
```

### 生成されたファイルを確認する

```bash
ruby2d/basic $ ls build/web
main.data  main.html  main.js  main.wasm
```

| ファイル | 役割 |
|---|---|
| `main.html` | ブラウザで開くページ本体 |
| `main.js` | WASMを読み込んで実行するJavaScript |
| `main.wasm` | Rubyのコードとruby2dのライブラリをコンパイルしたバイナリ |
| `main.data` | フォントなど、アプリが使うファイル一式 |

`main.rb` を1行も書き換えずに、この4つのファイルが生成されます。

#### *ここで試したいこと

- `ruby2d build --web --single-file main.rb` を実行して、`main.html` 1つだけにまとまることを確認しよう。
