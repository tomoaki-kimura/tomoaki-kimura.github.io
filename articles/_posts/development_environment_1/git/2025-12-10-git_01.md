### Gitとは

Gitは、ファイルの変更履歴を記録・管理するためのツール（バージョン管理システム）です。コードをいつ・どう変更したかを記録できるので、「前の状態に戻したい」「誰が何を変更したか確認したい」といったことができるようになります。

この後のカリキュラムで使う `git` コマンドや、GitHubへのコードの公開でも必要になるので、ここでインストールしておきます。

### インストールされているか確認する

まず、すでにGitが入っているかどうかをターミナルで確認しましょう。

```bash
$ git --version
```

`git version 2.xx.x` のように表示されればインストール済みです。この場合、以降の作業は不要です。

### Macでインストールする

Macの場合、`git --version` を実行した時点でインストールされていなければ、Xcodeのコマンドラインツールをインストールするかどうかのダイアログが表示されます。表示に従って「インストール」を選択すると、Gitを含む開発用のコマンドラインツール一式がインストールされます。

ダイアログが表示されない、または閉じてしまった場合は、以下のコマンドで改めてインストールを開始できます。

```bash
$ xcode-select --install
```

### Windowsでインストールする

Windowsの場合は、公式サイトからインストーラーをダウンロードします。

[https://git-scm.com/downloads/win](https://git-scm.com/downloads/win){:target="_blank"}

ダウンロードしたインストーラーを実行し、基本的にはすべて初期設定のまま「Next」を押し進めて構いません。インストールが終わったら、ターミナル（コマンドプロンプトやPowerShell）を開き直してください。

### インストールできたか確認する

再度、ターミナルで以下を実行します。

```bash
$ git --version
git version 2.xx.x
```

バージョンが表示されればインストール完了です。
