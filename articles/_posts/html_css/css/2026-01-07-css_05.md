## {{ page.section_title }}

### 要素にはblockとinlineがある

HTMLの要素は、初期状態でそれぞれ「ブロック要素」か「インライン要素」のどちらかの性質を持っています。

- **ブロック要素**（`div` `h1`〜`h6` `p` `section` `ul`など）— 横幅いっぱいに広がり、前後で必ず改行される
- **インライン要素**（`a` `span` `img`など）— 中身の分だけの幅になり、横に並ぶ

```html
<p>これは<a href="#">リンク</a>を含む文章です。</p>
```

`<a>`がインライン要素だからこそ、文章の途中にリンクを挟んでも改行されず、地の文と自然に並んで表示されます。

### displayプロパティで性質を変える

`display`プロパティを使うと、この性質を変更できます。

```css
li {
  display: inline; /* liは本来ブロック要素だが、横並びにしたいときに使う */
}
```

例えば`<nav>`の中の`<ul><li>`を横並びのメニューにしたいとき、`li`に`display: inline`（または後で学ぶ`flex`）を指定します。

### inline-blockという中間

`inline-block`は、「横に並べたいが、幅や高さも指定したい」ときに使います。

```css
.btn {
  display: inline-block;
  width: 120px;
  height: 40px;
}
```

インライン要素は本来、`width`や`height`を指定しても効果がありません（中身の分だけの幅・高さになる）。`inline-block`にすることで、横並びの性質を保ったまま、幅・高さも指定できるようになります。

| 指定 | 横に並ぶか | width/heightが効くか |
|---|---|---|
| `block` | 並ばない（改行される） | 効く |
| `inline` | 並ぶ | 効かない |
| `inline-block` | 並ぶ | 効く |
