### フォント系のプロパティ

文字に関するプロパティをまとめて紹介します。

```css
body {
  font-family: "Hiragino Sans", "Noto Sans JP", sans-serif;
  font-size: 16px;
  font-weight: normal;
  line-height: 1.6;
}

h1 {
  font-weight: bold;
}
```

- `font-family` — 使用するフォント。複数指定しておき、環境に無いフォントは次の候補が使われます（最後の`sans-serif`は「ゴシック体なら何でもよい」という保険）。
- `font-size` — 文字の大きさ
- `font-weight` — 文字の太さ（`normal`/`bold`など）
- `line-height` — 行の高さ。数値だけ書く（`1.6`など）と、文字サイズに対する倍率になります。行間が詰まって読みにくいときによく調整します。

### 色の指定方法

```css
h1 {
  color: red;             /* 色の名前 */
  color: #ff0000;         /* 16進数（赤緑青の順） */
  color: rgb(255, 0, 0);  /* RGB指定 */
  background-color: #f5f5f5;
}
```

`color`は文字色、`background-color`は背景色です。実務では`#ff0000`のような16進数指定が最もよく使われます。

### よく使う単位

大きさを指定する単位にはいくつか種類があります。

| 単位 | 意味 |
|---|---|
| `px` | ピクセル。画面上の絶対的な大きさ |
| `%` | 親要素に対する割合 |
| `em` | 親要素の文字サイズに対する倍率 |
| `rem` | ページ全体の基準（`html`要素）の文字サイズに対する倍率 |
| `vw` / `vh` | 画面の横幅・縦幅に対する割合（`100vw`で画面いっぱいの横幅） |

`em`は親の文字サイズが基準になるため、要素が入れ子になるほど計算が複雑になりがちです。そのため、文字サイズの指定には、常にページ全体の基準（`html`要素）だけを基準にする`rem`が使われることが多くなっています。

```css
html {
  font-size: 16px; /* 1rem = 16px の基準になる */
}

h1 {
  font-size: 2rem; /* 32px */
}
```

#### *ここで試したいこと

- `body`の`font-size`を`14px`にしてみたり、`h1`の`color`を16進数で好きな色に変えてみよう。

style.css

```css
  color: black;

}

  border-bottom: 1px solid gray;
  color: navy;
}

.btn {
  padding: 8px 16px;
  border-radius: 4px;
}
```
