### レイアウトの歴史

「要素を横に並べる」というだけのことに、CSSは長い間苦労してきました。

- **table時代** — 大昔は`<table>`タグでページ全体のレイアウトを組んでいました（HTMLチャプターで「本来は表データ専用」と学んだ、あの反省点です）。
- **float時代** — その後、本来「画像に文字を回り込ませる」ためのプロパティだった`float`を使って横並びを作る方法が主流になりました。ただし`float`は複雑な副作用（後続の要素の高さがおかしくなるなど）が多く、扱いにくいものでした。
- **Flexbox時代** — 2015年ごろから主要ブラウザで安定して使えるようになったのが**Flexbox**です。「横に並べる」「均等に配置する」を、専用の書き方で簡単に実現できるようになりました。現在はレイアウトの基本としてFlexboxを使うのが主流です。

### Flexboxの基本

親要素に`display: flex`をつけるだけで、その直接の子要素が横並びになります。

```css
nav ul {
  display: flex;
  list-style: none;
  gap: 24px;
}
```

`display: inline`で無理やり横並びにしていた回のことを思い出してください。Flexboxならこの1行で済みます。`gap`は要素同士の間隔を指定するプロパティで、Flexboxとセットでよく使われます。

### 並び・揃えを指定する

```css
header {
  display: flex;
  justify-content: space-between; /* 横方向の配置 */
  align-items: center;            /* 縦方向の配置 */
}
```

- `justify-content` — 横方向（主軸）の配置。`flex-start`（左寄せ）/`center`（中央）/`space-between`（両端に均等配置）など
- `align-items` — 縦方向（交差軸）の配置。`center`にすると縦方向の中央揃えができます

ロゴとナビゲーションを両端に配置しつつ、縦の中央で揃えたいときなどに、この2つの組み合わせをよく使います。

### hoverで演出をつける

マウスカーソルが要素の上に乗ったときのスタイルは、`:hover`という疑似クラスで指定します。

```css
nav a {
  color: black;
}
nav a:hover {
  color: navy;
  text-decoration: underline;
}
```

ボタンやリンクにカーソルを乗せたときに色が変わる、という動きはほとんどのサイトで使われている基本の演出です。
