### レスポンシブとは

パソコンとスマートフォンでは、画面の横幅が大きく違います。パソコンでは横並びでちょうどよいレイアウトも、スマートフォンの狭い画面でそのまま表示すると、文字が小さすぎたり、はみ出したりしてしまいます。画面の幅に応じてレイアウトを切り替えることを**レスポンシブデザイン**と呼びます。

### メディアクエリの基本

`@media`を使うと、「画面の幅が〇〇px以下のときだけ」といった条件でCSSを切り替えられます。

```css
.container {
  display: flex;
  gap: 24px;
}

@media (max-width: 600px) {
  .container {
    flex-direction: column;
  }
}
```

`flex-direction: column`は、Flexboxの並ぶ向きを「横」から「縦」に変えるプロパティです。画面幅が`600px`以下になったときだけこのスタイルが適用され、横並びだった要素が縦並びに切り替わります。

### なぜmax-widthで書くことが多いか

`@media (max-width: 600px)`は「600px以下のとき」という意味です。まずパソコン向けの見た目を基本として書いておき、画面が狭くなったときにスマートフォン向けの調整を`@media`で上書きする、という書き方（デスクトップファースト）がよく使われます。

### viewportの指定を忘れずに

メディアクエリを使う前提として、`<head>`に以下の記述が必要です。

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

これが無いと、スマートフォンのブラウザが「本当はパソコン用の幅で作られたページ」と誤解して、縮小表示してしまい、メディアクエリが意図通りに効きません。忘れずにセットで書く決まりごとだと覚えておきましょう。

- ブラウザの表示幅を狭くしてみて（開発者ツールのレスポンシブ表示モードが便利です）、`600px`をまたいだ瞬間にレイアウトが切り替わることを確認してみよう。
