## {{ page.section_title }}

### 複数のスタイルがぶつかったら

同じ要素に対して、複数のセレクタから別々の指定がされることがあります。

```css
h2 {
  color: black;
}

.section-title {
  color: navy;
}

#about {
  color: red;
}
```

```html
<h2 id="about" class="section-title">会社概要</h2>
```

この`h2`の文字色は何色になるでしょうか。答えは`red`です。これは「後に書いたほうが勝つ」わけではなく、**詳細度（Specificity）**という優先順位のルールで決まっています。

### 詳細度の強さ

大まかに、以下の順で強さが決まっています（下にいくほど強い）。

1. タグセレクタ（`h2`）— 一番弱い
2. classセレクタ（`.section-title`）
3. idセレクタ（`#about`）— 一番強い
4. HTMLタグに直接書くインラインスタイル（`style="color: green;"`）— さらに強い
5. `!important`をつけた指定 — 最強

先ほどの例では、`id`セレクタがタグ・classより強いため`red`が採用されました。

### id指定が中心にならなかった理由

前回、「classを中心に使う」という話をしましたが、詳細度の観点からも理由があります。`id`は詳細度が強すぎるため、後から別の指定で上書きしたくても、classでは`id`に勝てません。デザインの調整がしづらくなるため、`id`はスタイル指定にはあまり使わず、classで統一するのが今の主流です。

### !importantは基本使わない

`!important`は最強の指定ですが、多用すると「後から!importantでしか上書きできない」状態になり、収拾がつかなくなります。基本的には使わず、詳細度の低い書き方（classでの指定）で解決する方法を探すのが望ましいです。

#### *ここで試したいこと

- `.section-title`の`color`を`green`に変えても、`#about`の`red`が優先されて変わらないことを確認してみよう。

### ここまでのコード

style.css

```css
h1 {
  color: blue;
  font-size: 32px;
}

h2 {
  font-weight: bold;
  color: black;
}

#about {
  color: red;
}

.section-title {
  border-bottom: 1px solid gray;
  color: navy;
}

.btn {
  padding: 8px 16px;
  border-radius: 4px;
}
```

`h2`と`.section-title`は今回追加した`color`をそれぞれのルールに統合しています。`#about`は詳細度が一番強いため、実際の文字色は`red`になります。
