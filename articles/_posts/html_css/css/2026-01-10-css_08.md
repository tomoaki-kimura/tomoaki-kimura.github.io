## {{ page.section_title }}

### positionとは

`position`は、要素をどのように配置するかを決めるプロパティです。値によって、位置の基準がまったく変わります。

### static（初期値）

何も指定しないときの状態です。上から下に、書かれた順番どおりに配置されます。

### relative（相対配置）

`static`のときの位置を基準に、そこから`top`/`left`などでずらせます。**もともとあった場所のスペースは空けたまま**、見た目だけをずらすイメージです。

```css
.badge {
  position: relative;
  top: -5px;
  left: 10px;
}
```

### absolute（絶対配置）

`position: relative`（または`absolute`/`fixed`）を指定した**直近の親要素**を基準に、そこからの位置で配置します。他の要素の流れからは完全に外れます。

```css
.card {
  position: relative; /* 基準となる親 */
}
.card .label {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

「新着」ラベルをカードの右上に重ねて表示する、といった使い方が典型的です。`.card`に`position: relative`をつけておかないと、基準がカードではなく画面全体になってしまうので、セットで覚えておきましょう。

### fixed（固定配置）

画面（ブラウザのウィンドウ）を基準に固定されます。スクロールしても位置が動きません。

```css
header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}
```

ページをスクロールしても常に画面上部に表示され続ける「固定ヘッダー」でよく使われます。

### sticky（スティッキー配置）

普段は`static`のように振る舞いますが、スクロールしてある位置に達すると、そこで`fixed`のように固定されます。

```css
nav {
  position: sticky;
  top: 0;
}
```

### z-indexで重なり順を決める

`position`で位置を重ねられるようになると、「どちらを手前に表示するか」という重なり順の問題が出てきます。それを決めるのが`z-index`です。

```css
.modal {
  position: fixed;
  z-index: 100;
}
```

数値が大きいほど手前に表示されます。`z-index`は`position`が`static`以外（`relative`/`absolute`/`fixed`/`sticky`）の要素にしか効かない点に注意してください。
