### imgタグとbackground-imageの違い

HTMLチャプターで学んだ`<img>`は、「その画像自体が内容として意味を持つ」場合に使うタグでした（altテキストが必要だったのはそのためです）。一方、`background-image`は、あくまで**装飾**として要素の背景に画像を敷くためのCSSプロパティです。トップページの見出し部分に大きな背景写真を敷く、といった演出でよく使われます。

```css
.hero {
  background-image: url("images/hero.jpg");
  height: 400px;
}
```

パスの書き方は、HTMLチャプターで学んだファイルパスと同じ考え方です。

### よく一緒に使うプロパティ

```css
.hero {
  background-image: url("images/hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  height: 400px;
}
```

- `background-size: cover` — 要素の大きさに合わせて、縦横比を保ったまま画像が要素全体を覆うように拡大・縮小されます。写真がぼやけて見切れる部分ができても、要素からはみ出したり隙間ができたりしないのが特徴です。
- `background-position: center` — 画像の表示位置。`cover`ではみ出す部分がある場合、どこを中心に見せるかを指定します。
- `background-repeat: no-repeat` — `background-image`は初期状態でタイルのように繰り返し表示されるため、繰り返したくない写真では`no-repeat`を指定します。

### 背景に文字を重ねる

`position`の回で学んだ知識と組み合わせると、背景画像の上に見出しを重ねられます。

```html
<section class="hero">
  <h1>サンプル会社</h1>
</section>
```

```css
.hero {
  position: relative;
  background-image: url("images/hero.jpg");
  background-size: cover;
}
.hero h1 {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  color: white;
}
```

`transform: translate(-50%, -50%)`は、要素自身の幅・高さの半分だけ左上にずらすことで、`top: 50%; left: 50%;`だけでは左上の角が中央に来てしまうところを、要素全体を中央に配置するための定番の書き方です。
