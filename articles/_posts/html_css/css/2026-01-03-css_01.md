### なぜCSSがあるのか

HTMLチャプターで、`<h1>`は「大きな文字にするため」ではなく「見出しという意味を表すため」のタグだと学びました。では、実際の見た目（色・大きさ・配置など）はどこで決めるのでしょうか。それを担当するのがCSS（Cascading Style Sheets）です。

HTMLの初期の頃は、見た目の指定もHTMLタグの中に直接書かれていました（`<font color="red">`のような形です）。しかし、これでは「内容（HTML）」と「見た目（デザイン）」が混ざってしまい、デザインを変えるたびに大量のHTMLを書き換える必要がありました。そこで1996年ごろ、見た目の指定だけを別のファイルに分離する仕組みとしてCSSが登場しました。「内容はHTML、見た目はCSS」という役割分担が、現在まで続く基本の考え方です。

### CSSファイルを作って読み込む

HTMLチャプターの`<link>`タグの回で少し触れたとおり、CSSは別ファイルにして`<link>`で読み込みます。

```bash
my_site $ touch style.css
```

```html
<head>
  <meta charset="UTF-8">
  <title>福岡県の世界遺産</title>
  <link rel="stylesheet" href="style.css">
</head>
```

### CSSの基本構文

CSSは「どの要素に」「何を」「どうするか」を、以下の形で書きます。

```css
h1 {
  color: blue;
}
```

- `h1` — **セレクタ**（どの要素に適用するか）
- `color` — **プロパティ**（何を変えるか）
- `blue` — **値**（どうするか）

`プロパティ: 値;` の組み合わせを`{}`の中に必要なだけ並べられます。

```css
h1 {
  color: blue;
  font-size: 32px;
}
```

`;`（セミコロン）を書き忘れると、次の行がうまく認識されないことがあるので注意しましょう。
