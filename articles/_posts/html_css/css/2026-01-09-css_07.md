### 中身が箱に収まらないとき

前回学んだボックスモデルで、`width`や`height`を指定した箱に対して、中身（文章や画像）がその大きさに収まらないことがあります。

```css
.box {
  width: 200px;
  height: 100px;
  border: 1px solid #ddd;
}
```

このとき、はみ出した中身をどう表示するかを決めるのが`overflow`プロパティです。

```css
.box {
  width: 200px;
  height: 100px;
  border: 1px solid #ddd;
  overflow: visible; /* 初期値。箱からはみ出してそのまま表示される */
}
```

### overflowの主な値

- `visible`（初期値）— はみ出した部分もそのまま表示する
- `hidden` — はみ出した部分を切り取って見えなくする
- `scroll` — 常にスクロールバーを表示し、はみ出した部分はスクロールして見る
- `auto` — はみ出しているときだけ、自動的にスクロールバーを表示する

```css
.box {
  width: 200px;
  height: 100px;
  overflow: auto;
}
```

実務では、はみ出した分は隠したいときに`hidden`、内容が長くなるかもしれない箱（お知らせ一覧など）には`auto`がよく使われます。

#### *ここで試したいこと

- 長い文章を`.box`の中に入れて、`overflow`の値を`visible`・`hidden`・`auto`それぞれで見た目がどう変わるか比べてみよう。
