### すべての要素は箱（ボックス）

CSSでは、すべての要素が四角い箱として扱われます。この箱は、内側から順に4つの層でできています。

```
┌─────────── margin（外側の余白） ───────────┐
│ ┌───────── border（枠線） ─────────┐       │
│ │ ┌───── padding（内側の余白） ─────┐│      │
│ │ │        content（中身）        ││      │
│ │ └───────────────────────────────┘│      │
│ └───────────────────────────────────┘      │
└─────────────────────────────────────────────┘
```

- `content` — 実際の文字や画像が入る部分
- `padding` — 中身と枠線の間の余白
- `border` — 枠線
- `margin` — 他の要素との間の外側の余白

### marginとpaddingの違い

どちらも「余白」ですが、役割が違います。

```css
.card {
  padding: 16px;  /* 箱の内側の余白。背景色は塗られる */
  margin: 24px;   /* 箱の外側の余白。他の要素との間隔 */
  background-color: #f5f5f5;
  border: 1px solid #ddd;
}
```

`padding`は背景色の内側に含まれるため、背景色や枠線と中身の間の余白を作りたいときに使います。`margin`は背景色の外側なので、他の要素との間隔を空けたいときに使います。迷ったら「背景色を塗ったときに、余白部分も色がついてほしいか」で判断すると分かりやすいです。

### widthの落とし穴とbox-sizing

```css
.card {
  width: 300px;
  padding: 16px;
  border: 1px solid #ddd;
}
```

初期状態のCSSでは、`width: 300px`と指定しても、実際に画面上に表示される幅は「300px + paddingの左右32px + borderの左右2px = 334px」になります。`width`は`content`だけの幅を指定するもので、`padding`と`border`は含まれない、という仕様のためです。これは初心者がほぼ全員つまずくポイントです。

`box-sizing: border-box`を指定すると、`width`に`padding`と`border`を含めた「見た目どおりの幅」として扱ってくれるようになります。

```css
* {
  box-sizing: border-box;
}
```

このように`*`（すべての要素）に対して指定しておくのが定番です。実務のCSSでは、ファイルの先頭でほぼ必ずこの指定をすると考えて構いません。

#### *ここで試したいこと

- `box-sizing: border-box`をつけたときと外したときで、`.card`の実際の見た目の幅がどう変わるか確認してみよう。
