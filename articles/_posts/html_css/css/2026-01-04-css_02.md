### 3種類のセレクタ

前回の`h1`のように、タグ名をそのまま書くセレクタの他に、`id`と`class`という指定方法があります。

```html
<h2 id="about" class="section-title">会社概要</h2>
```

```css
/* タグセレクタ：h2というタグすべてが対象 */
h2 {
  font-weight: bold;
}

/* idセレクタ：id="about" を持つ要素だけが対象 */
#about {
  color: navy;
}

/* classセレクタ：class="section-title" を持つ要素すべてが対象 */
.section-title {
  border-bottom: 1px solid gray;
}
```

- タグセレクタ：そのタグ名を直接書く（`h2`）
- idセレクタ：`#`をつける（`#about`）。`id`は1ページに1つしか使えません。
- classセレクタ：`.`をつける（`.section-title`）。`class`は同じ名前を何個の要素にもつけられます。

### 現在はclassが中心

`id`は「ページの中でここだけ」という一点指定にしか使えないため、同じデザインを複数の要素に使い回したいとき（ボタン・カードなど）には不便です。`class`は同じ名前を何度でも使い回せるため、現在のCSS設計では基本的に**class中心**で組み立てます。

```html
<button class="btn">送信する</button>
<button class="btn">キャンセル</button>
```

```css
.btn {
  padding: 8px 16px;
  border-radius: 4px;
}
```

2つのボタンに同じ`.btn`をつけるだけで、同じ見た目を使い回せます。`id`は、JavaScriptで「この要素だけをピンポイントで操作したい」ときなど、CSS以外の用途で使われることが今は多くなっています。
