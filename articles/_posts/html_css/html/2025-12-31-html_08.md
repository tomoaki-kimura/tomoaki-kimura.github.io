### formタグでお問い合わせフォームを作る

`<form>` は、ユーザーが情報を入力して送信するためのタグです。コーポレートサイトの「お問い合わせフォーム」を例に作ってみましょう。

```html
<section>
  <h2>お問い合わせ</h2>
  <form action="/contact" method="post">
    <div>
      <label for="name">お名前</label>
      <input type="text" id="name" name="name">
    </div>
    <div>
      <label for="email">メールアドレス</label>
      <input type="email" id="email" name="email">
    </div>
    <div>
      <label for="message">お問い合わせ内容</label>
      <textarea id="message" name="message"></textarea>
    </div>
    <button type="submit">送信する</button>
  </form>
</section>
```

このカリキュラムの段階では、`action`（送信先）は実際にはまだ何も受け取れる場所がないので、動作としては送信できません（ダミーの状態）。この先、SQLやSinatraを学んだあとで、実際に送信内容をデータベースに保存できるように育てていきます。

### inputのtype属性

`<input>` は `type` 属性によって見た目や振る舞いが変わります。

```html
<input type="text">     <!-- 1行のテキスト -->
<input type="email">    <!-- メールアドレス用（形式チェックが入る） -->
<input type="checkbox"> <!-- チェックボックス -->
<input type="radio">    <!-- ラジオボタン（複数の中から1つ選ぶ） -->
<input type="submit">   <!-- 送信ボタン（button type="submit"と同じ役割） -->
```

### labelとinputを紐付ける

`<label for="name">` の `for` と、`<input id="name">` の `id` を同じ値にすることで、ラベルと入力欄が結びつきます。この紐付けには2つの意味があります。

1. ラベルの文字をクリックしても、対応する入力欄にカーソルが移動する（クリックできる範囲が広がる）
2. スクリーンリーダーが「これは何を入力する欄か」を正しく読み上げられる

`for`と`id`の対応を忘れると、見た目は同じでもアクセシビリティが失われるので注意しましょう。

#### *ここで試したいこと

- 「お問い合わせ種別」として、`type="radio"` を2〜3個追加してみよう（例: 「見積り依頼」「取材依頼」「その他」）。
