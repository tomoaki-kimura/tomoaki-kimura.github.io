## {{ page.section_title }}

### 見出しタグとは

`<h1>` から `<h6>` までは見出しを表すタグです。数字が小さいほど大きな見出し（重要度が高い）になります。`body` の中を以下のようにしてみましょう。

```html
<body>
  <h1>福岡県の世界遺産</h1>
  <h2>世界遺産について</h2>
  <h3>登録の背景</h3>
  <h2>構成資産</h2>
</body>
```

### 見た目の大きさのためのタグではない

`<h1>` は大きな文字で表示されますが、それは結果であって目的ではありません。見出しタグは「文章の階層構造」を表すためのタグです。本の目次をイメージすると分かりやすいです。

- `<h1>` = 章タイトル（ページに1つが基本）
- `<h2>` = 節タイトル
- `<h3>` = さらにその中の項目

「大きな文字にしたいから `<h1>` を使う」というのは誤った使い方です。文字を大きくしたいだけなら、後で学ぶCSSを使います。

### 階層を飛ばさない

`<h1>` の次にいきなり `<h4>` を使う、といった階層の飛ばしは避けましょう。スクリーンリーダー（画面を読み上げるソフト）は見出しの階層をたどってページ構造を把握するので、階層が飛んでいると内容の理解がしづらくなります。

### h1は基本1つ

1つのページの中で `<h1>` は、そのページ全体のテーマを表すものとして基本的に1つだけにします。今回の例では「福岡県の世界遺産」が `<h1>` にあたります。
