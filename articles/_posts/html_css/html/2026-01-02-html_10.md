### アクセシビリティとは

アクセシビリティとは、目が見えない・見えにくい方や、マウスがうまく使えない方など、さまざまな人がWebページを問題なく利用できるようにすることです。特に、画面を読み上げる「スクリーンリーダー」というソフトを使っている方にとって、HTMLの書き方は非常に重要です。ここまでの内容を、アクセシビリティの観点で振り返ります。

### 1. 見出しの階層を守る（第3回）

スクリーンリーダーには、見出しだけを一覧して読み上げ、ページの構造を素早く把握する機能があります。`<h1>`から順番に、階層を飛ばさずに使うことが大切でした。

### 2. 意味のあるタグを使う（第4回）

`<header>` `<nav>` `<main>` のようなタグを使うと、スクリーンリーダーは「今はナビゲーションの中にいる」「ここからが本文だ」と伝えることができます。すべてを`<div>`で書いてしまうと、この情報が失われます。

### 3. altテキストを書く（第6回）

画像の`alt`は、目が見えないユーザーにとってその画像の唯一の情報源でした。装飾目的の画像は`alt=""`にして読み上げをスキップさせる、という使い分けも学びました。

### 4. tableは表データにだけ使う（第7回）

`<table>`を使うと、スクリーンリーダーは「表である」と認識して読み上げ方を変えます。レイアウト目的で使わない、というのはアクセシビリティの観点からも重要でした。

### 5. labelとinputを紐付ける（第8回）

`for`と`id`が対応していないと、スクリーンリーダーは入力欄が何を入力する欄なのか伝えられません。フォームでは特に重要なポイントです。

### aria属性という選択肢もある

HTMLの標準タグだけでは意味を伝えきれない場合、`aria-*`という特別な属性を補助的に使うこともできます。例えば、見た目はボタンだが`<button>`タグが使えない事情があるとき、`role="button"`を指定したり、アイコンだけのボタンに`aria-label="メニューを開く"`を指定して読み上げ用のテキストを補ったりします。

```html
<button aria-label="メニューを開く">
  ☰
</button>
```

ただし、`aria-*`は「正しいHTMLタグが使えないときの最後の手段」という位置づけです。まずは今回学んだ意味のあるタグ（`<nav>`や`<button>`など）を正しく使うことが優先で、aria属性はその補助、と覚えておきましょう。

### まとめ

特別なことをしなくても、ここまで学んできた「意味に合ったタグを選ぶ」という考え方そのものが、アクセシビリティ対応の基本です。次はCSSで、今回作ったコーポレートサイトの見た目を整えていきます。

### ここまでのコード

今回は新しいタグを追加していないので、`index.html`は前回から変わっていません。

index.html

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>コーポレートサイト</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <img src="images/logo.png" alt="サンプル会社のロゴ">
    <h1>コーポレートサイト</h1>
    <nav>
      <a href="#about">会社概要</a>
    </nav>
  </header>

  <main>
    <section id="about">
      <h2>会社概要</h2>
      <p>2020年創業のWeb制作会社です。</p>
    </section>

    <section>
      <h2>サービス紹介</h2>
      <ul>
        <li>Web制作</li>
        <li>ロゴデザイン</li>
        <li>SEO対策</li>
      </ul>
    </section>

    <section>
      <h2>ご利用の流れ</h2>
      <ol>
        <li>お問い合わせ</li>
        <li>お見積り</li>
        <li>ご契約</li>
        <li>制作開始</li>
      </ol>
    </section>

    <section>
      <h2>料金プラン</h2>
      <table>
        <thead>
          <tr>
            <th>プラン</th>
            <th>ページ数</th>
            <th>料金</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td>ライト</td>
            <td>5ページ</td>
            <td>50,000円</td>
          </tr>
          <tr>
            <td>スタンダード</td>
            <td>10ページ</td>
            <td>100,000円</td>
          </tr>
        </tbody>
      </table>
    </section>

    <section>
      <h2>お問い合わせ</h2>
      <form action="/contact" method="post">
        <div>
          <label for="name">お名前</label>
          <input type="text" id="name" name="name">
        </div>
        <div>
          <label for="email">メールアドレス</label>
          <input type="email" id="email" name="email">
        </div>
        <div>
          <label for="message">お問い合わせ内容</label>
          <textarea id="message" name="message"></textarea>
        </div>
        <button type="submit">送信する</button>
      </form>
    </section>
  </main>

  <footer>
    <address>
      サンプル会社<br>
      〒000-0000 東京都〇〇区〇〇1-2-3<br>
      <a href="mailto:info@example.com">info@example.com</a>
    </address>
    <small>&copy; 2026 サンプル会社</small>
  </footer>
</body>
</html>
```
