## {{ page.section_title }}

### aタグ（アンカータグ）でリンクを貼る

`<a>` は、Webページ同士やページ内の別の場所へのリンクを作るタグです。`href`（hyper reference）属性にリンク先を指定します。

```html
<a href="https://example.com">外部サイトへのリンク</a>
<a href="about.html">会社概要ページへ</a>
<a href="#about">ページ内の「会社概要」セクションへ</a>
```

外部サイトへのリンクを新しいタブで開きたい場合は `target="_blank"` を使いますが、多用しすぎるとユーザーが混乱する（タブが増えすぎる）ので、外部サイトへ移動する場合など、必要なところだけに使いましょう。

### linkタグで外部ファイルを読み込む

`<link>` は `<a>` とは違い、リンク先に「移動する」タグではなく、外部ファイルをこのページに**読み込む**ためのタグです。主にCSSファイルの読み込みに使います。`<head>` の中に書きます。

```html
<head>
  <meta charset="UTF-8">
  <title>コーポレートサイト</title>
  <link rel="stylesheet" href="style.css">
</head>
```

`<a>`＝「移動する」、`<link>`＝「読み込む」、と役割で覚えておくと混同しません。

### imgタグで画像を表示する

`<img>` は画像を表示するタグです。`<a>`や`<link>`と違って、閉じタグ（`</img>`）は書きません。

```html
<img src="images/logo.png" alt="サンプル会社のロゴ">
```

`src`（source）に画像ファイルへのパスを指定します。前に学んだファイルパスの知識がここで使われます。

### altは省略しない

`img`タグの`alt`属性は、画像が表示できなかったときの代替テキストであると同時に、スクリーンリーダーが画像の内容を読み上げるための情報でもあります。目が見えないユーザーにとっては、`alt`がその画像の唯一の情報源になります。「ロゴ画像」のような曖昧な説明ではなく、「サンプル会社のロゴ」のように、その画像が何を表しているかが伝わる書き方をしましょう。

見た目だけの装飾画像で、内容として意味を持たない場合は `alt=""`（空）にして、読み上げの対象から除外することもできます。

#### *ここで試したいこと

- `images` フォルダに適当な画像を1枚入れて、`<img>` で表示してみよう。存在しないファイル名を指定するとどうなるか（altテキストが表示される）も試してみよう。
