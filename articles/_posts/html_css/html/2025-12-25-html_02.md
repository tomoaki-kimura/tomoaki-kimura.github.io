### HTML文書の基本の型

前回は見出しと文章だけを書きましたが、本来HTMLのファイルには決まった「型」があります。`index.html` を以下のように書き直してみましょう。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのサイト</title>
</head>
<body>
  <h1>はじめてのHTML</h1>
  <p>これは最初のページです。</p>
</body>
</html>
```

### 1行ずつ見ていく

- `<!DOCTYPE html>` — 「このファイルはHTML5で書かれています」という宣言です。必ずファイルの一番上に書きます。
- `<html lang="ja">` — ページ全体を囲むタグです。`lang="ja"` は「このページの言語は日本語です」という指定で、読み上げソフト（スクリーンリーダー）が正しい発音で読み上げるためにも使われます。
- `<head>` — ブラウザの画面には表示されない、ページの設定情報を書く場所です。
- `<body>` — ブラウザの画面に実際に表示される内容を書く場所です。

### headの中身

`<head>` の中には、以下のようなタグをよく書きます。

- `<meta charset="UTF-8">` — このファイルの文字コードがUTF-8であることの宣言。前回の「保存形式」と対応しています。
- `<title>はじめてのサイト</title>` — ブラウザのタブに表示されるタイトルです。

試しに `<title>` の中身を変えて保存し、ブラウザのタブの表示が変わることを確認してみましょう。

### headとbodyの覚え方

`<head>`＝画面には映らない設定、`<body>`＝画面に映る中身、とシンプルに覚えておけば十分です。次回以降、`<body>` の中にいろいろなタグを追加していきます。

#### *ここで試したいこと

- `<title>` の中身を自分の名前に変えて、タブの表示が変わるか確認してみよう。
