### divとは

`<div>` は、ページの一部をグループにまとめるための、**それ自体には意味を持たない**タグです。CSSでレイアウトを組むときの入れ物として使います。

```html
<div>
  <h2>会社概要</h2>
  <p>2020年創業のWeb制作会社です。</p>
</div>
```

### 意味を持つタグを使おう（HTML5のセマンティック要素）

`<div>` は便利ですが、何にでも使ってしまうと「このかたまりが何なのか」がコードを読むだけでは分かりません。HTML5では、役割ごとに意味を持ったタグが用意されています。

| タグ | 意味 |
|---|---|
| `<header>` | ページやセクションの先頭部分（ロゴ・サイトタイトルなど） |
| `<nav>` | ナビゲーション（メニューのリンクをまとめる部分） |
| `<main>` | そのページの中心となるメインコンテンツ（ページに1つ） |
| `<article>` | それ単体で完結する記事・投稿など |
| `<section>` | ひとまとまりのテーマを持つ区画（見出しとセットで使うことが多い） |
| `<aside>` | 補足情報・関連リンクなど、本筋から少し離れた内容 |
| `<footer>` | ページやセクションの末尾部分（コピーライトなど） |

これらを使って、前回までの中身を書き直してみましょう。

```html
<body>
  <header>
    <h1>コーポレートサイト</h1>
    <nav>
      <a href="#about">会社概要</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>会社概要</h2>
      <p>2020年創業のWeb制作会社です。</p>
    </section>
  </main>

  <footer>
    <small>&copy; 2026 サンプル会社</small>
  </footer>
</body>
```

### divとsectionの使い分け

迷ったときの目安は「見出し（`<h2>`など）とセットで、ひとまとまりのテーマがあるか」です。あるなら`<section>`、単にCSSのためだけにまとめたいなら`<div>`、と考えるとよいでしょう。すべてを`<div>`で書いても表示は崩れませんが、コードの意味が伝わりやすくなり、スクリーンリーダーにとっても情報を整理しやすくなります。

#### *ここで試したいこと

- `<main>` の中に、`<section>` をもう1つ追加して、`<h2>サービス紹介</h2>` と本文を書いてみよう。
