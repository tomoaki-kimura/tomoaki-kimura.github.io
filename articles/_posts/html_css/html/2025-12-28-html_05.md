### リストの2種類

リストを作るタグには2種類あります。

- `<ul>`（Unordered List）— 順序に意味のない箇条書き
- `<ol>`（Ordered List）— 順序に意味のあるリスト（手順・ランキングなど）

どちらも、中に `<li>`（List Item）でリストの項目を並べます。

### ulの例

構成資産の一覧のように、並び順に意味がない場合は `<ul>` を使います。

```html
<section>
  <h2>構成資産</h2>
  <ul>
    <li>河内貯水池</li>
    <li>遠賀川水源地ポンプ室</li>
    <li>官営八幡製鐵所</li>
  </ul>
</section>
```

### olの例

手順のように、順番に意味がある場合は `<ol>` を使います。

```html
<section>
  <h2>見学の流れ</h2>
  <ol>
    <li>事前予約</li>
    <li>集合場所の確認</li>
    <li>ガイドの案内</li>
    <li>見学</li>
  </ol>
</section>
```

`<ol>` はブラウザが自動的に「1. 2. 3.」のような番号をつけて表示してくれます。

### リストは入れ子にできる

`<li>` の中にさらに `<ul>` や `<ol>` を入れることで、階層のあるリストも作れます。

```html
<ul>
  <li>官営八幡製鐵所
    <ul>
      <li>旧本事務所</li>
      <li>修繕工場</li>
    </ul>
  </li>
  <li>遠賀川水源地ポンプ室</li>
</ul>
```

#### *ここで試したいこと

- `<nav>` の中のメニューを `<ul>`/`<li>` で書き直してみよう（`<nav><ul><li><a>...</a></li></ul></nav>` という組み合わせは、実際のサイトでもよく使われる形です）。
