## {{ page.section_title }}

### リストの2種類

リストを作るタグには2種類あります。

- `<ul>`（Unordered List）— 順序に意味のない箇条書き
- `<ol>`（Ordered List）— 順序に意味のあるリスト（手順・ランキングなど）

どちらも、中に `<li>`（List Item）でリストの項目を並べます。

### ulの例

サービス一覧のように、並び順に意味がない場合は `<ul>` を使います。

```html
<section>
  <h2>サービス紹介</h2>
  <ul>
    <li>Web制作</li>
    <li>ロゴデザイン</li>
    <li>SEO対策</li>
  </ul>
</section>
```

### olの例

手順のように、順番に意味がある場合は `<ol>` を使います。

```html
<section>
  <h2>ご利用の流れ</h2>
  <ol>
    <li>お問い合わせ</li>
    <li>お見積り</li>
    <li>ご契約</li>
    <li>制作開始</li>
  </ol>
</section>
```

`<ol>` はブラウザが自動的に「1. 2. 3.」のような番号をつけて表示してくれます。

### リストは入れ子にできる

`<li>` の中にさらに `<ul>` や `<ol>` を入れることで、階層のあるリストも作れます。

```html
<ul>
  <li>Web制作
    <ul>
      <li>コーポレートサイト</li>
      <li>ECサイト</li>
    </ul>
  </li>
  <li>ロゴデザイン</li>
</ul>
```

#### *ここで試したいこと

- `<nav>` の中のメニューを `<ul>`/`<li>` で書き直してみよう（`<nav><ul><li><a>...</a></li></ul></nav>` という組み合わせは、実際のサイトでもよく使われる形です）。

index.html

```html
  <title>コーポレートサイト</title>

  <header>
    <h1>コーポレートサイト</h1>
    <nav>
      <a href="#about">会社概要</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>会社概要</h2>
      <p>2020年創業のWeb制作会社です。</p>
    </section>

    <section>
      <h2>サービス紹介</h2>
      <ul>
        <li>Web制作</li>
        <li>ロゴデザイン</li>
        <li>SEO対策</li>
      </ul>
    </section>

    <section>
      <h2>ご利用の流れ</h2>
      <ol>
        <li>お問い合わせ</li>
        <li>お見積り</li>
        <li>ご契約</li>
        <li>制作開始</li>
      </ol>
    </section>
  </main>

  <footer>
    <small>&copy; 2026 サンプル会社</small>
  </footer>
</body>
</html>
```
