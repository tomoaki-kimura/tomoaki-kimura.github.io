## {{ page.section_title }}

### addressタグ

`<address>` は、そのページ（または`<article>`）の作成者・運営者の連絡先情報を表すタグです。名前のとおり「住所」専用ではなく、メールアドレスや電話番号なども含みます。`<footer>`の中でよく使われます。

```html
<footer>
  <address>
    福岡県の世界遺産 案内事務局<br>
    北九州市・中間市 産業遺産めぐり<br>
    <a href="mailto:info@example.com">info@example.com</a>
  </address>
  <small>&copy; 2026 HearthSide プログラミングスクール</small>
</footer>
```

### smallタグ

`<small>` は見た目を小さくするだけのタグではなく、著作権表示・免責事項・注釈など「本文に対する補足的な小さな文字」という意味を持つタグです。上の例のコピーライト表記のような使い方が典型的です。

### brタグは「便利だけど使いすぎ注意」

`<br>`（break）は、その場で改行するタグです。

```html
福岡県の世界遺産 案内事務局<br>
北九州市・中間市 産業遺産めぐり<br>
```

上の住所表記のように、「意味のある改行」（住所の区切りなど）には使って構いません。しかし、文章と文章の間を空けたい、要素同士の余白を作りたい、といった**見た目の調整のためだけに**`<br>`を連打するのは避けましょう。

```html
<!-- あまり良くない例 -->
<p>1行目の文章です。</p>
<br><br><br>
<p>2行目の文章です。</p>
```

このような余白の調整は、この先学ぶCSSの`margin`というプロパティで行うのが正しいやり方です。`<br>`を見た目の調整に使ってしまうと、後でデザインを変えたいときにHTMLを触らないといけなくなり、修正が大変になります。
