### HTMLとは・簡単な歴史

HTML（HyperText Markup Language）は、Webページの内容や構造を表すための言語です。1991年ごろ、CERNのTim Berners-Lee氏によって考案されました。その後何度もバージョンアップを重ね、2014年に標準化された**HTML5**が現在の基本になっています。このカリキュラムでもHTML5の書き方を扱います。

### ファイルを作る

VSCodeで、作業用のフォルダを作り、その中に `index.html` というファイルを作成します。

```bash
$ mkdir my_site
$ cd my_site
my_site $ touch index.html
```

`index.html` という名前には理由があります。多くのWebサーバーは、フォルダの中にアクセスがあったとき、特に指定がなければ `index.html` というファイルを自動的に表示する決まりになっています。トップページのファイル名は基本的に `index.html` にする、と覚えておきましょう。

### 保存形式（文字コード）

HTMLファイルを保存するときは、**文字コード**を意識する必要があります。文字コードとは、コンピューターの中で文字をどう表現するかの規格です。現在のWeb制作では、ほぼ`UTF-8`という文字コードで統一されています。VSCodeは基本的にUTF-8で保存してくれますが、右下のステータスバーで確認できます。文字コードが違うファイルをブラウザで開くと、日本語が文字化けすることがあります。

### 最初の中身を書く

`index.html` に、試しに以下を書いてみましょう。

```html
<h1>はじめてのHTML</h1>
<p>これは最初のページです。</p>
```

### ブラウザで表示する

保存したら、VSCodeの左のファイル一覧から `index.html` を右クリックし、「Reveal in Finder」（Macの場合）などでファイルの場所を開き、ダブルクリックしてブラウザで開いてみましょう。あるいは、ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

見出しと文章が表示されていれば成功です。

### ファイルパスの基本

Webページを作っていくと、画像ファイルなど`index.html`以外のファイルも増えていきます。そのとき、「今いる場所からの相対的な位置」を表すのがファイルパスです。

```
my_site/
├── index.html
└── images/
    └── logo.png
```

この場合、`index.html` から見て `images/logo.png` のように、フォルダ名を `/` でつないでパスを表します。今後、画像やCSSファイルを読み込むときにこの書き方を使います。

#### *ここで試したいこと

- `my_site` フォルダの中に `images` というフォルダをもう1つ作ってみよう（中身は空でよい）。
