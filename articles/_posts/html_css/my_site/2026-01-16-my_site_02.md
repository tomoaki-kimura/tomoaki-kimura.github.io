### 画像を用意する

`images`フォルダを作り、河内貯水池・遠賀川水源地ポンプ室・八幡製鐵所の写真（フリー素材や自分で撮った写真など）を用意しておきましょう。ヒーロー用に横長の写真を1枚、`images/hero.jpg`として保存します。

```bash
my_site $ mkdir images
```

### 背景画像を敷く

CSSチャプターで学んだ`background-image`を使います。

```css
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: "Hiragino Sans", "Noto Sans JP", sans-serif;
  line-height: 1.7;
}

.hero {
  position: relative;
  height: 400px;
  background-image: url("images/hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

`*`に対する`box-sizing: border-box`と`margin: 0; padding: 0;`は、ブラウザごとの初期スタイルの違いをなくすための、実務でも定番の書き出しです。

### タイトルを写真の上に重ねる

CSSチャプターの`position`と`background-image`の回で学んだ書き方を組み合わせます。

```css
.hero h1 {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  color: white;
  font-size: 2rem;
  text-align: center;
  text-shadow: 0 2px 8px rgba(0, 0, 0, 0.6);
}
```

`.hero`に`position: relative`を指定しているので、`.hero h1`の`position: absolute`はこの`.hero`を基準に配置されます。`transform: translate(-50%, -50%)`で、写真のちょうど中央にタイトルが来るようにしています。`text-shadow`は文字に影をつけるプロパティで、写真の上に白文字を乗せるときに、背景が明るい部分でも文字が読みやすくなるように使っています。

昔ながらのランディングページでよく見る「背景写真の上に大きなキャッチコピー」という定番の作りが、これで再現できました。

#### *ここで試したいこと

- `.hero`の`height`を`500px`や`300px`に変えて、写真の見え方がどう変わるか確認してみよう。
