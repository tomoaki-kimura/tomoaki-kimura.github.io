## {{ page.section_title }}

### スマートフォンでの見え方を確認する

ブラウザの表示幅を狭くしてみましょう。3枚のパネルが横に並んだまま縮んでいき、幅が狭くなるほど写真や文字が窮屈になっていきます。スマートフォンの画面でこのまま表示すると、文字が小さすぎて読みにくくなってしまいます。

### メディアクエリで縦並びに切り替える

CSSチャプターで学んだ`@media`と、Flexboxの`flex-direction`を組み合わせます。

```css
@media (max-width: 600px) {
  .panels {
    flex-direction: column;
    padding: 20px;
  }

  .hero h1 {
    font-size: 1.5rem;
  }
}
```

`flex-direction: column`によって、画面幅が`600px`以下になったときだけ、3枚のパネルが縦に並ぶようになります。あわせて、ヒーローのタイトルも少し小さくして、狭い画面でも収まりが良くなるようにしています。

### 開発者ツールで確認する

ブラウザの開発者ツールには、スマートフォンの画面幅をシミュレートできるモードがあります（Chromeなら`command + shift + M`）。これを使って、`600px`をまたいだ瞬間にレイアウトが切り替わることを確認しましょう。

#### *ここで試したいこと

- `max-width: 600px`の値を`900px`に変えて、レイアウトが切り替わるタイミングがどう変わるか確認してみよう。
