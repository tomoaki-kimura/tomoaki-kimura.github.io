### HTMLに写真と本文を追加する

前回作った`.panels`の中身を、実際の説明文と写真入りに書き換えます。

```html

      高さ43.1m・幅189mの石造りの堰堤は、完成当時「東洋一のダム」と

    </p>
  </article>
```

`alt`には、それぞれの写真が何を写しているかが伝わる説明を入れています。

### Flexboxで横並びにする

```css
.panels {
  display: flex;
  gap: 24px;
  padding: 40px;
}

.panel {
  flex: 1;
  background-color: #f5f5f0;
  border-radius: 8px;
  overflow: hidden;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

.panel img {
  width: 100%;
  height: 200px;
  object-fit: cover;
}

.panel h3,
.panel p {
  padding: 0 20px;
}

.panel h3 {
  padding-top: 16px;
}

.panel p {
  padding-bottom: 20px;
}
```

`flex: 1`を3つの`.panel`すべてに指定することで、3枚が均等な幅で横並びになります。`overflow: hidden`は、CSSチャプールで学んだプロパティです。`border-radius`で角を丸くしたカードの中に、四角い`img`がそのままはみ出さないように使っています。

### object-fitで画像の比率を保つ

`object-fit: cover`は`background-size: cover`の`img`タグ版です。写真の縦横比を保ったまま、指定した`width`/`height`の枠を覆うように表示してくれます。3枚の写真の縦横比がバラバラでも、カードの高さを揃えられます。

#### *ここで試したいこと

- `.panels`の`gap`を`0`にしてみて、パネル同士がぴったりくっつく見た目と比べてみよう。
