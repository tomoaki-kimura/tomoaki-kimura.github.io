## {{ page.section_title }}

### 作るサイトのテーマ

ここまでのHTML・CSSチャプターで学んだタグやプロパティを使って、1つのシングルページサイトを作ります。テーマは「水が結ぶ、八幡製鉄所の記憶」。世界遺産「明治日本の産業革命遺産」の構成資産である官営八幡製鐵所と、その操業を支えた2つの水インフラ（遠賀川水源地ポンプ室・河内貯水池）を、3枚のパネルで紹介するページです。

### ファイルを作る

```bash
$ mkdir my_site
$ cd my_site
my_site $ touch index.html style.css
```

### 骨組みを作る

いきなり見た目を作らず、まず「意味のあるタグ」で骨組みを作ります。HTMLチャプターで学んだセマンティック要素を使いましょう。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>水が結ぶ、八幡製鉄所の記憶</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header class="hero">
    <h1>水が支えた、近代製鉄の記憶</h1>
  </header>

  <main>
    <section class="intro">
      <h2>今も現役で稼働する、産業遺産</h2>
      <p>
        鉄をつくるには、大量の水が必要です。鋼1トンをつくるのに200トン以上の水が使われるといわれています。
        官営八幡製鐵所の拡張とともに、水を確保するための2つの施設が作られました。
        どちらも建設から100年以上たった今も、現役で稼働し続けています。
      </p>
    </section>

    <section class="panels">
      <article class="panel">
        <h3>河内貯水池</h3>
        <p>1927年完成。堰堤は高さ43.1m、貯水量約700万トン。</p>
      </article>
      <article class="panel">
        <h3>遠賀川水源地ポンプ室</h3>
        <p>1910年建設・操業開始。今も工業用水の約7割を送り続けています。</p>
      </article>
      <article class="panel">
        <h3>官営八幡製鐵所</h3>
        <p>1901年操業開始。日本で最初の本格的な官営製鉄所です。</p>
      </article>
    </section>
  </main>

  <footer>
    <address>
      北九州市・中間市 産業遺産めぐり
    </address>
    <small>&copy; 2026 HearthSide プログラミングスクール</small>
  </footer>
</body>
</html>
```

`<header>`をページ全体のヒーロー（トップ）として、`<main>`の中に`<section>`を2つ（導入文・3施設のパネル）、パネル1つ1つは単体でも意味が完結する内容なので`<article>`を使っています。

この段階ではCSSをまだ書いていないので、見た目は縦一列に並んだ味気ない状態です。次回から少しずつ見た目を整えていきます。
