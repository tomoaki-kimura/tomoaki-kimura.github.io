## {{ page.section_title }}

### 手順はRubyのときと同じ

前回、Rubyを管理するために次の3ステップを行いました。

1. `asdf plugin add` でpluginを追加する
2. `asdf install` でバージョンをインストールする
3. `asdf set` で使うバージョンを指定する

この手順は、Ruby以外の言語やツールでもまったく同じです。ここではJavaScriptを動かすための `nodejs` と、そのパッケージ管理ツールである `yarn` を例に、もう一度同じ手順を確認します。

### nodejsを追加する

```bash
$ asdf plugin add nodejs
$ asdf install nodejs 22.x.x
$ asdf set nodejs 22.x.x
```

確認します。

```bash
$ node -v
v22.x.x
```

### yarnを追加する

```bash
$ asdf plugin add yarn
$ asdf install yarn 1.22.x
$ asdf set yarn 1.22.x
```

確認します。

```bash
$ yarn -v
1.22.x
```

### .tool-versionsに複数書かれる

`asdf set` を同じディレクトリで何度か行うと、`.tool-versions` に言語ごとの行が追加されていきます。

```bash
$ cat .tool-versions
ruby 3.4.3
nodejs 22.x.x
yarn 1.22.x
```

1つのプロジェクトの中で、Ruby・Node.js・Yarnなど複数の言語やツールのバージョンを、このファイル1つでまとめて管理できます。新しく参加した人がこのリポジトリを取得したときも、`asdf install` を実行するだけで、`.tool-versions` に書かれた組み合わせを再現できます。

#### *ここで試したいこと

- `asdf plugin list` で、今までに追加したpluginの一覧を確認してみよう。
- `asdf current` で、今のディレクトリで実際に使われている各言語のバージョンを確認してみよう。
