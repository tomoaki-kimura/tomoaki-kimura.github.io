## {{ page.section_title }}

### asdfとは

asdfは、Ruby・Node.jsなど、いろいろな言語のバージョンをまとめて管理・切り替えできるツールです。「このプロジェクトではRuby 3.4系を使う」「あのプロジェクトでは3.2系を使う」といったことを、プロジェクトごとに簡単に切り替えられるようになります。

### インストールする

Homebrewを使ってインストールします。

```bash
$ brew install asdf
```

### インストールできたか確認する

ターミナルを開き直してから、以下を実行します。

```bash
$ asdf version
0.xx.x
```

バージョンが表示されれば、インストールできています。

#### *ここで試したいこと

- `asdf plugin list all` を実行して、asdfで管理できる言語・ツールの一覧を眺めてみよう。
