## {{ page.section_title }}

### pluginを追加する

asdfは、言語ごとに「plugin」という形で対応を追加していきます。まずはRuby用のpluginを追加します。

```bash
$ asdf plugin add ruby
```

### インストールできるバージョンを確認する

```bash
$ asdf list all ruby
```

インストール可能なRubyのバージョンが、たくさん一覧表示されます。

### バージョンをインストールする

使いたいバージョンを指定してインストールします。

```bash
$ asdf install ruby 3.4.3
```

### バージョンを切り替える

インストールしただけでは、まだそのバージョンが使われるわけではありません。`asdf set` で「どこで、どのバージョンを使うか」を設定します。

```bash
$ asdf set ruby 3.4.3
```

これを実行したディレクトリに `.tool-versions` というファイルが作られ、そこに使用するバージョンが記録されます。

### .tool-versionsファイルを見てみる

実は、このカリキュラムサイト自身のリポジトリにも `.tool-versions` があります。

```bash
$ cat .tool-versions
ruby 3.4.3
```

このファイルがあるディレクトリ以下では、`ruby` コマンドを実行すると自動的にここに書かれたバージョンが使われます。プロジェクトごとにこのファイルを持たせることで、複数のプロジェクトで違うバージョンのRubyを同時に使い分けられます。

### 確認する

```bash
$ ruby -v
ruby 3.4.3 ...
```

`.tool-versions` に書いたバージョンが使われていることを確認できます。

#### *ここで試したいこと

- `asdf current` を実行して、現在使われているバージョン一覧を確認してみよう。
