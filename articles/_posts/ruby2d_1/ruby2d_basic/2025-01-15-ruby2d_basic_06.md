## {{ page.section_title }}

### ruby2d console とは

`ruby2d console xxx.rb` を実行すると、ウィンドウとターミナルのコンソールが同時に起動します。コンソールに Ruby のコードを1行ずつ入力して、ウィンドウをリアルタイムに操作できます。

- ファイルにエラーがある場合 → コンソールのみ開く（ウィンドウは開かない）
- 重大なエラーの場合 → どちらも開かない

### 最小限のファイルを用意する

main.rb

```ruby
require "ruby2d"

show
```

### コンソールを起動する

```bash
ruby2d/basic $ ruby2d console main.rb
```

黒いウィンドウとコンソール入力欄が起動する。

### コンソールで円を作る

コンソールに以下を1行ずつ入力してみよう。

```
> c = Circle.new(x: 200, y: 200, radius: 50)
```

ウィンドウに白い円が現れる。

```
> c.color = "red"
```

円が赤くなる。

```
> c.x = 400
```

円が右に移動する。

### Rectangle と Text も試してみよう

```
> r = Rectangle.new(x: 50, y: 50, width: 150, height: 60, color: "blue")
> r.height = 120
> t = Text.new("hello", x: 60, y: 60, size: 28, color: "yellow")
> t.text = "Ruby2D!"
```

### オブジェクトを消す

```
> c.remove
```

円が画面から消える。

### コンソールを終了する

```
> exit
```

または `Ctrl + C` で終了する。

#### *ここで試したいこと

- `c.color = "green"` → `c.color = "purple"` と順番に打って色が変わることを確認しよう。
- `c.radius = 100` で円を大きくしてみよう。
- 変数を使わずに `Circle.new(x: 300, y: 300, radius: 30, color: "pink")` と打つとどうなるか試してみよう（消せなくなる）。
