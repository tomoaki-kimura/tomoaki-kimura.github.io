## {{ page.section_title }}

### rand とは

`rand(n)` は `0` 以上 `n` 未満の整数をランダムに返します。

```ruby
rand(6)   # => 0, 1, 2, 3, 4, 5 のどれか
rand(1..6) # => 1, 2, 3, 4, 5, 6 のどれか
```

### Array#sample とは

配列の中からランダムに1つ取り出します。

```ruby
colors = ["red", "blue", "green"]
colors.sample  # => "red" か "blue" か "green"
```

### 一定確率で色を変える

`rand(60) == 0` は 60 回に 1 回だけ `true` になります。これを使うと「たまに」色が変わります。

main.rb

```ruby
require "ruby2d"

COLORS = %w(red orange yellow green blue purple fuchsia)

c = Circle.new(x: 0, y: 0, radius: 30, color: "white")
x_speed = 4
y_speed = 3

update do
  c.x += x_speed
  c.y += y_speed
  x_speed = -x_speed if c.x < 0 || c.x > Window.width
  y_speed = -y_speed if c.y < 0 || c.y > Window.height

  c.color = COLORS.sample if rand(60) == 0
end

show
```

`COLORS` は定数です。`%w(...)` で文字列の配列を作ります。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

円が跳ね返りながら動き続け、不規則なタイミングで色が変わる。

### ruby2d console でも試してみよう

コンソールで `COLORS.sample` を何度も打って、毎回違う色が返ってくることを確認しよう。

```bash
ruby2d/basic $ ruby2d console main.rb
```

```
> COLORS.sample
> COLORS.sample
> COLORS.sample
```

#### *ここで試したいこと

- `rand(60)` を `rand(5)` に変えて色が変わる頻度を上げてみよう。
- `rand(60) == 0` を `tick % 30 == 0` に変えると規則正しく変わる（`tick` は何フレーム目かを数える変数）。
- 速さもランダムにしてみよう。`x_speed = rand(2..6)` `y_speed = rand(2..6)` を色変更と一緒に実行する。
