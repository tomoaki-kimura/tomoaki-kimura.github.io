## {{ page.section_title }}

### Circle を表示する

main.rb

```ruby
require "ruby2d"

Circle.new(x: 200, y: 150, radius: 50)

show
```

- `x:` — 円の中心のX座標
- `y:` — 円の中心のY座標
- `radius:` — 半径

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

画面に白い円が表示される。

### 色を変える

main.rb（`Circle.new` を更新）

```ruby
Circle.new(x: 200, y: 150, radius: 50, color: "red")
```

`color:` に文字列で色名を渡します。`"blue"`・`"green"`・`"yellow"` なども使えます。

### 複数の Circle を並べる

main.rb

```ruby
require "ruby2d"

Circle.new(x: 100, y: 200, radius: 30, color: "red")
Circle.new(x: 250, y: 200, radius: 50, color: "blue")
Circle.new(x: 420, y: 200, radius: 20, color: "yellow")

show
```

`Circle.new` を何行も書くと複数表示できます。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

3つの円が並んで表示される。

#### *ここで試したいこと

- `radius:` を大きくしたり小さくしたりしてみよう。
- `x:` と `y:` を変えて円を好きな場所に移動させよう。
- `"orange"`・`"purple"`・`"fuchsia"` など他の色も試してみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

Circle.new(x: 100, y: 200, radius: 30, color: "red")
Circle.new(x: 250, y: 200, radius: 50, color: "blue")
Circle.new(x: 420, y: 200, radius: 20, color: "yellow")

show
```
