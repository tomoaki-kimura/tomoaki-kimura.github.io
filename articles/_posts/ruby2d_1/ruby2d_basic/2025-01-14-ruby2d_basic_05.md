### 変数に入れて後から変更する

これまでは `Circle.new(...)` の中にすべての設定を書いていました。変数に入れると、後から個別に変更できます。

main.rb

```ruby
require "ruby2d"

c = Circle.new
c.x      = 200
c.y      = 200
c.radius = 50
c.color  = "red"

show
```

`Circle.new` の引数を省略して `new` だけにして、プロパティを1行ずつ設定しています。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

赤い円が表示される。見た目は前と変わらない。

### 複数のオブジェクトを変数で管理する

main.rb

```ruby
require "ruby2d"

c = Circle.new(x: 100, y: 200, radius: 30, color: "blue")
r = Rectangle.new(x: 200, y: 150, width: 200, height: 100, color: "green")
t = Text.new("Hello!", x: 210, y: 165, size: 24, color: "white")

c.color = "orange"
r.width = 300
t.text  = "Ruby2D!"

show
```

変数に入れておくと、`Circle.new` した後でも `c.color = "orange"` のように書き換えられます。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

オレンジの円、横に伸びた緑の四角、`Ruby2D!` というテキストが表示される。

#### *ここで試したいこと

- `c.x = 300` を追加して円の位置を変えてみよう（`show` の前ならどこに書いても反映される）。
- `t.color = "yellow"` を追加してテキストの色を変えてみよう。
- `r.color = [0.5, 0, 1, 1]` を試してみよう。

### ここまでのコード

```ruby
require "ruby2d"

c = Circle.new(x: 100, y: 200, radius: 30, color: "blue")

r.width = 300
t.text  = "Ruby2D!"

show
```
