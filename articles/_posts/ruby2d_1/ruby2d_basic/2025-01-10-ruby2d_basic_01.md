## {{ page.section_title }}

### ディレクトリを作る

```bash
$ mkdir ruby2d
$ cd ruby2d
```

### Rubyのバージョンを切り替える

ruby2d はバージョン1.0.0からRuby 4.0以上が必須になりました。このカリキュラムサイトの環境構築で使っているRuby 3.4系とは別に、このディレクトリだけRuby 4系を使うように切り替えます。

```bash
ruby2d $ asdf install ruby 4.0.1
ruby2d $ asdf set ruby 4.0.1
ruby2d $ ruby -v
ruby 4.0.1 ...
```

### ruby2d をインストールする

このディレクトリの中で、以下を実行します。

```bash
ruby2d $ gem install ruby2d
```

`Successfully installed ruby2d` と表示されればOKです。

### basicディレクトリとファイルを作る

```bash
ruby2d $ mkdir basic
ruby2d $ cd basic
ruby2d/basic $ touch main.rb
```

### ウィンドウを開く

main.rb

```ruby
require "ruby2d"

show
```

`require "ruby2d"` で ruby2d を読み込み、`show` でウィンドウを立ち上げます。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

黒いウィンドウが表示される。閉じるには右上の × をクリックするかターミナルで `Ctrl + C` を押す。

#### *ここで試したいこと

- ウィンドウのサイズを変えてみよう。`show` の前に `set width: 400, height: 300` を追加する。
- `set title: "はじめてのruby2d"` を追加してウィンドウのタイトルを変えてみよう。
