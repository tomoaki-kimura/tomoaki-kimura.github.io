## {{ page.section_title }}

### update do とは

`update do ... end` の中に書いた処理は、1秒間に60回（60fps）自動で繰り返されます。ここに座標を少しずつ変える処理を書くと、オブジェクトが動いて見えます。

### 円を右に動かす

main.rb

```ruby
require "ruby2d"

c = Circle.new(x: 0, y: 200, radius: 20, color: "red")

update do
  c.x += 3
end

show
```

`c.x += 3` で毎フレーム x 座標が 3 ずつ増え、円が右へ動き続けます。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

赤い円が左から右へ動き続け、画面外に消える。

### 画面端で折り返す

右端まで行ったら左端に戻すようにします。

main.rb（`update do` を更新）

```ruby
update do
  c.x += 3
  c.x = 0 if c.x > Window.width
end
```

`Window.width` はウィンドウの横幅です（デフォルト 640）。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

円が右端まで来ると左端に戻り、ループし続ける。

### 上下にも動かす

main.rb（変数と `update do` を変更）

```ruby
c = Circle.new(x: 0, y: 0, radius: 20, color: "red")
x_speed = 3
y_speed = 2

update do
  c.x += x_speed
  c.y += y_speed
  x_speed = -x_speed if c.x < 0 || c.x > Window.width
  y_speed = -y_speed if c.y < 0 || c.y > Window.height
end
```

壁に当たるたびに速さの符号を反転させます。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

円が画面の中を壁で跳ね返りながら動き続ける。

#### *ここで試したいこと

- `x_speed` と `y_speed` の値を変えて速さを変えてみよう。
- `Rectangle` や `Text` を `update do` で動かしてみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

c = Circle.new(x: 0, y: 0, radius: 20, color: "red")
x_speed = 3
y_speed = 2

update do
  c.x += x_speed
  c.y += y_speed
  x_speed = -x_speed if c.x < 0 || c.x > Window.width
  y_speed = -y_speed if c.y < 0 || c.y > Window.height
end

show
```
