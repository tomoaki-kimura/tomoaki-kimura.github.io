## {{ page.section_title }}

### Rectangle を表示する

main.rb

```ruby
require "ruby2d"

Rectangle.new(x: 100, y: 100, width: 200, height: 80, color: "blue")

show
```

- `width:` — 横幅
- `height:` — 縦の高さ
- `x:` / `y:` — 左上角の座標

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

青い長方形が表示される。

### Circle と組み合わせる

main.rb

```ruby
require "ruby2d"

Rectangle.new(x: 100, y: 150, width: 300, height: 40, color: "green")
Circle.new(x: 250, y: 130, radius: 30, color: "orange")

show
```

後から書いたものが手前に表示されます（描画の順番）。

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

緑の長方形の上にオレンジの円が重なって表示される。

#### *ここで試したいこと

- `width:` と `height:` を同じ値にしてみよう（正方形になる）。
- `Circle.new` と `Rectangle.new` の順番を入れ替えると表示がどう変わるか確認しよう。
- `color:` に `[1, 0, 0, 0.5]` を渡してみよう（R・G・B・透明度の配列で指定できる）。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

Rectangle.new(x: 100, y: 150, width: 300, height: 40, color: "green")
Circle.new(x: 250, y: 130, radius: 30, color: "orange")

show
```
