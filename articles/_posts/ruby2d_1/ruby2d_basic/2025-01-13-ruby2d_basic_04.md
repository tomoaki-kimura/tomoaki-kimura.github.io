## {{ page.section_title }}

### Text を表示する

main.rb

```ruby
require "ruby2d"

Text.new("Hello, Ruby2D!", x: 100, y: 200, size: 30)

show
```

- 最初の引数に表示したい文字列を渡します
- `size:` — 文字の大きさ
- `x:` / `y:` — 左上角の座標

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

白い文字が表示される。

### 色を変える

main.rb（`Text.new` を更新）

```ruby
Text.new("Hello, Ruby2D!", x: 100, y: 200, size: 30, color: "yellow")
```

### 他のオブジェクトと組み合わせる

main.rb

```ruby
require "ruby2d"

Rectangle.new(x: 0, y: 0, width: 640, height: 60, color: "navy")
Text.new("Score: 100", x: 10, y: 10, size: 30, color: "white")
Circle.new(x: 320, y: 300, radius: 80, color: "red")

show
```

### ファイルの実行

```bash
ruby2d/basic $ ruby main.rb
```

### 結果

紺色のバーの上に白いスコアテキスト、その下に赤い円が表示される。

#### *ここで試したいこと

- `size:` を変えて文字の大きさを変えてみよう。
- 好きなメッセージに変えてみよう（日本語も使える）。
- `x:` や `y:` を変えて文字の位置を調整しよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

Rectangle.new(x: 0, y: 0, width: 640, height: 60, color: "navy")
Text.new("Score: 100", x: 10, y: 10, size: 30, color: "white")
Circle.new(x: 320, y: 300, radius: 80, color: "red")

show
```
