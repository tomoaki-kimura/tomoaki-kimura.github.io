## {{ page.section_title }}

### ファイルの作成

ターミナルで以下を実行して、`river` ディレクトリと `main.rb` を作ります。

```bash
$ mkdir ruby2d/river
$ cd ruby2d/river
ruby2d/river $ touch main.rb
```

### 川とボートを表示する

`Rectangle` を画面いっぱいに敷いて川に見立て、その上に自機のボートを表示します。

main.rb

```ruby
require "ruby2d"

# 川（背景）
river = Rectangle.new(width: Window.width, height: Window.height, color: "blue")

# ボート
boat = Rectangle.new(width: 60, height: 30, color: "brown")
boat.x = (Window.width - boat.width) / 2
boat.y = Window.height - boat.height * 2

show
```

`river` を先に作ってから `boat` を作ることで、ボートが川の上に重なって表示されます。

### ファイルの実行

```bash
ruby2d/river $ ruby main.rb
```

### 結果

画面いっぱいに青い川が表示され、その下のほうにボートが浮かんでいる状態になる。

#### *ここで試したいこと

- `river` の `color` を変えて、川の色を変えてみよう。
- `boat.y` の値を変えて、ボートの上下位置を変えてみよう。
