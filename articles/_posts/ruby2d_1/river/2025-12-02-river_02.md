## {{ page.section_title }}

### キー操作を追加する

`on :key_down` を使って、キーが押されたときの処理を書きます。

main.rb

```ruby
(略)

on :key_down do |event|
  case event.key
  when "left"
    boat.x -= 20 if boat.x > 0
  when "right"
    boat.x += 20 if boat.x < Window.width - boat.width
  end
end

show
```

`boat.x > 0` や `boat.x < Window.width - boat.width` の条件で、ボートが画面の外に出ないように制限しています。

### ファイルの実行

```bash
ruby2d/river $ ruby main.rb
```

### 結果

矢印キーの `←` `→` でボートが左右に動く。画面の端まで行くとそれ以上は動かない。

#### *ここで試したいこと

- `20` の部分を変えて、ボートが動く速さを変えてみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

# 川（背景）
river = Rectangle.new(width: Window.width, height: Window.height, color: "blue")

# ボート
boat = Rectangle.new(width: 60, height: 30, color: "brown")
boat.x = (Window.width - boat.width) / 2
boat.y = Window.height - boat.height * 2

on :key_down do |event|
  case event.key
  when "left"
    boat.x -= 20 if boat.x > 0
  when "right"
    boat.x += 20 if boat.x < Window.width - boat.width
  end
end

show
```
