## {{ page.section_title }}

### 岩を配列で作る

1つだった `rock` を、`times.map` を使って複数の `Circle` が入った配列 `rocks` に変えます。

main.rb

```ruby
require "ruby2d"

# 川（背景）
river = Rectangle.new(width: Window.width, height: Window.height, color: "blue")

# ボート
boat = Rectangle.new(width: 60, height: 30, color: "brown")
boat.x = (Window.width - boat.width) / 2
boat.y = Window.height - boat.height * 2

# 岩（3つ）
rock_count = 3
rocks = rock_count.times.map do |i|
  Circle.new(radius: 15, color: "gray", x: rand(0..Window.width), y: -i * 150)
end

status = :playing

(略)
```

`y: -i * 150` で、3つの岩の開始位置を150ずつずらしています。こうすることで、岩が一列に並ばず、ばらばらのタイミングで流れてくるようになります。

### 配列に合わせて処理を書き換える

`rock` を使っていた部分を、`rocks.each` で1つずつ取り出す形に書き換えます。

main.rb

```ruby
(略)

on :key_down do |event|
  if status == :playing
    case event.key
    when "left"
      boat.x -= 20 if boat.x > 0
    when "right"
      boat.x += 20 if boat.x < Window.width - boat.width
    end
  end

  if event.key == "r" && status == :game_over
    status = :playing
    boat.x = (Window.width - boat.width) / 2
    rocks.each_with_index do |rock, i|
      rock.y = -i * 150
      rock.x = rand(0..Window.width)
    end
    message.each { |text| text.remove }
  end
end

update do
  if status == :playing
    rocks.each do |rock|
      rock.y += 4
      if rock.y > Window.height
        rock.y = 0
        rock.x = rand(0..Window.width)
      end
      if boat.contains?(rock.x, rock.y)
        status = :game_over
        message.each { |text| text.add }
      end
    end
  end
end

show
```

`rocks.each do |rock| ... end` で、配列の中の岩を1つずつ取り出して、それぞれに同じ処理（落ちる・画面外で戻る・当たり判定）を行っています。

### ファイルの実行

```bash
ruby2d/river $ ruby main.rb
```

### 結果

3つの岩がタイミングをずらしながら流れてきて、どれか1つでもボートに当たるとゲームオーバーになる。

#### *ここで試したいこと

- `rock_count` の数を増やして、岩をもっとたくさん流してみよう。
- `-i * 150` の `150` を変えて、岩の間隔を変えてみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

# 川（背景）
river = Rectangle.new(width: Window.width, height: Window.height, color: "blue")

# ボート
boat = Rectangle.new(width: 60, height: 30, color: "brown")
boat.x = (Window.width - boat.width) / 2
boat.y = Window.height - boat.height * 2

# 岩（3つ）
rock_count = 3
rocks = rock_count.times.map do |i|
  Circle.new(radius: 15, color: "gray", x: rand(0..Window.width), y: -i * 150)
end

status = :playing

# ゲームオーバー画面
message = [
  Text.new("GAME OVER", size: 30, x: 220, y: 200),
  Text.new("press key 'R' to restart", size: 20, x: 190, y: 260)
]
message.each { |text| text.remove }

on :key_down do |event|
  if status == :playing
    case event.key
    when "left"
      boat.x -= 20 if boat.x > 0
    when "right"
      boat.x += 20 if boat.x < Window.width - boat.width
    end
  end

  if event.key == "r" && status == :game_over
    status = :playing
    boat.x = (Window.width - boat.width) / 2
    rocks.each_with_index do |rock, i|
      rock.y = -i * 150
      rock.x = rand(0..Window.width)
    end
    message.each { |text| text.remove }
  end
end

update do
  if status == :playing
    rocks.each do |rock|
      rock.y += 4
      if rock.y > Window.height
        rock.y = 0
        rock.x = rand(0..Window.width)
      end
      if boat.contains?(rock.x, rock.y)
        status = :game_over
        message.each { |text| text.add }
      end
    end
  end
end

show
```
