### 岩を表示する

`Circle` で岩を作ります。

main.rb

```ruby
(略)

# 岩
rock = Circle.new(radius: 15, color: "gray")
rock.x = rand(0..Window.width)
rock.y = 0

on :key_down do |event|
(略)
```

`rand(0..Window.width)` で、岩の横位置をランダムな数にしています。

### 岩を毎フレーム動かす

`update do` の中に書いた処理は、画面が描画されるたびに（1秒間に何十回も）くり返し実行されます。

main.rb

```ruby
(略)

update do
  rock.y += 4
  if rock.y > Window.height
    rock.y = 0
    rock.x = rand(0..Window.width)
  end
end

show
```

岩が画面の下（`Window.height` より下）まで流れたら、`rock.y` を `0` に戻し、`rock.x` も新しいランダムな位置に変えることで、岩がずっと流れ続けているように見せています。

### ファイルの実行

```bash
ruby2d/river $ ruby main.rb
```

### 結果

岩がランダムな横位置から下に向かって流れ、画面の外に出るとまた上から流れてくる。

#### *ここで試したいこと

- `rock.y += 4` の `4` を変えて、岩の流れる速さを変えてみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

# 川（背景）
river = Rectangle.new(width: Window.width, height: Window.height, color: "blue")

# ボート
boat = Rectangle.new(width: 60, height: 30, color: "brown")
boat.x = (Window.width - boat.width) / 2
boat.y = Window.height - boat.height * 2

# 岩
rock = Circle.new(radius: 15, color: "gray")
rock.x = rand(0..Window.width)
rock.y = 0

on :key_down do |event|
  case event.key
  when "left"
    boat.x -= 20 if boat.x > 0
  when "right"
    boat.x += 20 if boat.x < Window.width - boat.width
  end
end

update do
  rock.y += 4
  if rock.y > Window.height
    rock.y = 0
    rock.x = rand(0..Window.width)
  end
end

show
```
