### スコアで難易度を変える

スコアが上がるにつれて敵が速くなり、出現頻度も増えます。

スコア ÷ 500 を「難易度レベル」として使います。

| スコア | 難易度レベル | スポーン間隔 |
|--------|------------|-------------|
| 0〜499 | 0 | 20フレーム |
| 500〜999 | 1 | 18フレーム |
| 1000〜1499 | 2 | 16フレーム |
| … | … | … (最短8フレーム) |

### app/main.rb のスポーン処理を更新する

app/main.rb（:start ブロックのスポーン部分を変更）

```ruby
when :start
  fighter.opening_action
  fighter.update_invincible
  Bullet.move(bullets, enemies, burns, items, @status)
  items.each { |item| item.move }
  items.each { |item| item.touch(fighter, items) }

  diff_level = @status.score / 500
  spawn_rate = [20 - diff_level * 2, 8].max

  enemies << Enemy1.new if tick % spawn_rate == 0 && rand(0..2) == 0
  enemies << Enemy2.new if tick % (spawn_rate + 5) == 0 && rand(0..2) == 0
  enemies << Enemy3.new if @status.score >= 300 && tick % 25 == 0 && rand(0..2) == 0

  enemies.each do |enemy|
    enemy.move(enemies)
    fighter.bloken_by(enemy, enemies)
  end
  Burn.selected_delete(burns)
  if fighter.life <= 0
    fighter.remove
    @status.to_game_over
    game_over.add
  end
```

`[20 - diff_level * 2, 8].max` は「20から下がっていくが最短8フレームまで」という意味です。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

最初はゆっくり敵が出るが、スコアが増えるにつれて出現頻度が上がっていく。

#### *ここで試したいこと

- `500` を小さくして（例：`200`）難易度が上がるペースを速めてみよう。
- `[20 - diff_level * 2, 8].max` の `8` を変えて最高難易度の上限を変えてみよう。
- `p diff_level` を入れてターミナルで確認してみよう。

### ここまでのコード

app/main.rb（全文）

```ruby
require "./config"

@status = Status.new
fighter = Fighter.new
game_title = GameTitle.new
game_over = GameOver.new
bullets = []
stars = []
items = []
enemies = []
burns = []
tick = 0

update do
  Star.set(stars) if tick % 10 == 0
  Star.move(stars)

  case @status.game_status
  when :title
  when :start
    fighter.opening_action
    fighter.update_invincible
    Bullet.move(bullets, enemies, burns, items, @status)
    items.each { |item| item.move }
    items.each { |item| item.touch(fighter, items) }

    diff_level = @status.score / 500
    spawn_rate = [20 - diff_level * 2, 8].max

    enemies << Enemy1.new if tick % spawn_rate == 0 && rand(0..2) == 0
    enemies << Enemy2.new if tick % (spawn_rate + 5) == 0 && rand(0..2) == 0
    enemies << Enemy3.new if @status.score >= 300 && tick % 25 == 0 && rand(0..2) == 0

    enemies.each do |enemy|
      enemy.move(enemies)
      fighter.bloken_by(enemy, enemies)
    end
    Burn.selected_delete(burns)
    if fighter.life <= 0
      fighter.remove
      @status.to_game_over
      game_over.add
    end
  end
  tick += 1
end

on :key do |event|
  key = event.key
  case fighter.status
  when :ready
    fighter.move(key)
  end
end

on :key_down do |event|
  key = event.key
  case key
  when "space"
    if @status.game_status == :title
      game_title.remove
      fighter.status = :clear
      @status.to_start
      fighter.add
    end
  when "j"
    if fighter.status == :ready
      Bullet.set(bullets, fighter)
    end
  when "r"
    if @status.game_status == :game_over
      game_over.remove
      [enemies, bullets, items, burns].each { |arr| arr.each(&:remove); arr.clear }
      fighter.reset
      fighter.status = :clear
      fighter.add
      @status.reset_score
      @status.to_start
    end
  end
end

on :key_up do |event|
  fighter.nutral(event.key)
end

show
```
