## {{ page.section_title }}

### Fighter に bloken_by メソッドを追加する

敵が `hit_area` の4点のどれかに重なっていたらライフを減らします。

app/models/fighter.rb（`reload_life` と `bloken_by` を追加）

```ruby
def bloken_by(enemy, enemies)
  self.hit_area.each do |area|
    if enemy.contains?(*area)
      self.life -= 1
      reload_life
      enemy.remove
      enemies.delete(enemy)
      break
    end
  end
end

private

def reload_life
  self.life_gauge.remove
  self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
end
```

`reload_life` は `private` に入れます。`Text` は値を書き換えられないので、いったん消して新しいものを作り直しています。

### app/main.rb で bloken_by を呼び出す

app/main.rb（:start ブロックに追加）

```ruby
enemies.each do |enemy|
  enemy.move(enemies)
  fighter.bloken_by(enemy, enemies)
end
```

これまで別々に書いていた `enemies.each { |enemy| enemy.move(enemies) }` を `bloken_by` とまとめます。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

敵に触れるたびにライフが1減り、画面左上の表示が更新される。ライフが0になっても今はまだゲームが続く。

#### *ここで試したいこと

- 敵に何度も当たってライフの表示が正しく更新されるか確認しよう。
- `hit_area` の `offset` を変えてどの範囲で当たり判定が発生するか試してみよう。

### ここまでのコード

app/models/fighter.rb（bloken_by・reload_life を追加した全文）

```ruby
class Fighter < Sprite
  attr_accessor :speed, :tick, :status, :pow, :level, :life, :life_gauge

  def initialize
    super("app/images/fighter.png")
    self.width = 30
    self.height = 30
    self.clip_width = 15
    self.clip_height = 15
    self.speed = 3.0
    self.remove
    self.tick = 0
    self.status = nil
    self.pow = 0
    self.level = 1
    self.life = 3
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end

  def move(key)
    right_move if key == "d"
    left_move  if key == "a"
    self.y -= self.speed if key == "w"
    self.y += self.speed if key == "s"
    window_limit
  end

  def nutral(key)
    center_image if key == "d" || key == "a"
  end

  def opening_action
    case self.status
    when :clear
      self.x = (Window.width - self.width) / 2
      self.y = Window.height - self.height
      self.status = :starting
    when :starting
      self.y -= 1
      self.color = "random"
      if self.y < Window.height / 4 * 3
        self.status = :ready
        self.color = "white"
      end
    end
  end

  def hit_area
    offset = 10
    offset_map = [offset * -1, offset]
    area = []
    offset_map.each do |y|
      offset_map.each do |x|
        area << [
          self.x + self.width / 2 + x,
          self.y + self.height / 2 + y
        ]
      end
    end
    area
  end

  def power_up
    if self.level < 3
      if self.pow < 2
        self.pow += 1
      else
        self.pow = 0
        self.level += 1
      end
    end
  end

  def power_down
    self.level -= 1 if self.level > 0
    self.pow = 0
  end

  def bloken_by(enemy, enemies)
    self.hit_area.each do |area|
      if enemy.contains?(*area)
        self.life -= 1
        reload_life
        enemy.remove
        enemies.delete(enemy)
        break
      end
    end
  end

  private

  def right_move
    self.x += self.speed
    self.clip_x = 15
    self.flip_sprite(nil)
  end

  def left_move
    self.x -= self.speed
    self.clip_x = 15
    self.flip_sprite(:horizontal)
  end

  def center_image
    self.clip_x = 0
    self.flip_sprite(nil)
  end

  def window_limit
    self.y = 0 if self.y < 0
    self.y = Window.height - self.height if self.y > Window.height - self.height
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end

  def reload_life
    self.life_gauge.remove
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end
end
```
