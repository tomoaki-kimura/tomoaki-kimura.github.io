## {{ page.section_title }}

### on :key と on :key_down の違い

| イベント | タイミング |
|---------|-----------|
| `on :key_down` | キーを押した瞬間（1回だけ） |
| `on :key` | キーを押している間、毎フレーム |

自機の移動には「押している間ずっと動く」`on :key` を使います。

### Fighter に move メソッドを追加する

app/models/fighter.rb

```ruby
class Fighter < Sprite
  attr_accessor :speed, :status, :pow, :level, :life, :life_gauge

  def initialize
    # 前回と同じ
  end

  def move(key)
    self.x += self.speed if key == "d"
    self.x -= self.speed if key == "a"
    self.y -= self.speed if key == "w"
    self.y += self.speed if key == "s"
    window_limit
  end

  private

  def window_limit
    self.y = 0 if self.y < 0
    self.y = Window.height - self.height if self.y > Window.height - self.height
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end
```

`private` より下のメソッドは、クラスの外から呼び出せません。`window_limit` は `move` の中からしか使わないので `private` にしています。

### app/main.rb に on :key を追加する

app/main.rb

```ruby
(略)

on :key do |event|
  key = event.key
  case fighter.status
  when :ready
    fighter.move(key)
  end
end

(略)
```

ただし、今はまだ `fighter.status` が `:ready` になりません。次のセクションでオープニングの後に `:ready` に変更します。

一時的に動作確認したい場合は、`case fighter.status` の判定を外してみましょう。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

スペースで自機が出現し、WASDで上下左右に動く。画面の端で止まる。

#### *ここで試したいこと

- `speed` の値を変えて動きの速さを変えてみよう。
- 画面の端に到達したときの挙動を確認しよう。

### ここまでのコード

app/models/fighter.rb

```ruby
class Fighter < Sprite
  attr_accessor :speed, :status, :pow, :level, :life, :life_gauge

  def initialize
    super("app/images/fighter.png")
    self.width = 30
    self.height = 30
    self.clip_width = 15
    self.clip_height = 15
    self.speed = 3.0
    self.remove
    self.status = nil
    self.pow = 0
    self.level = 1
    self.life = 3
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end

  def move(key)
    self.x += self.speed if key == "d"
    self.x -= self.speed if key == "a"
    self.y -= self.speed if key == "w"
    self.y += self.speed if key == "s"
    window_limit
  end

  private

  def window_limit
    self.y = 0 if self.y < 0
    self.y = Window.height - self.height if self.y > Window.height - self.height
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end
```

app/main.rb

```ruby
require "./config"

@status = Status.new
fighter = Fighter.new
game_title = GameTitle.new

update do
  case @status.game_status
  when :title
  when :start
  end
end

on :key do |event|
  key = event.key
  case fighter.status
  when :ready
    fighter.move(key)
  end
end

on :key_down do |event|
  key = event.key
  case key
  when "space"
    if @status.game_status == :title
      game_title.remove
      @status.to_start
      fighter.x = (Window.width - fighter.width) / 2
      fighter.y = Window.height / 2
      fighter.add
    end
  end
end

show
```
