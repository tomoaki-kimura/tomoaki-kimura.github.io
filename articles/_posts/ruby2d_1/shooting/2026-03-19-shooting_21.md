### Enemy3クラスを作る

Enemy1・Enemy2と同じ構造で、サイズ・速さ・色だけ変えます。

`app/models/enemy_3.rb` を新規作成しましょう。

app/models/enemy_3.rb

```ruby
class Enemy3 < Sprite
  SCORE = 200
  attr_accessor :speed

  def initialize
    super("./app/images/enemy_1.png",
      width: 15,
      height: 15,
      animations: {
        roll: [
          { width: 15, height: 15, x: 0,  y: 0  },
          { width: 15, height: 15, x: 15, y: 0  },
          { width: 15, height: 15, x: 0,  y: 15 },
          { width: 15, height: 15, x: 15, y: 15 }
        ]
      }
    )
    self.x = rand(0..(Window.width - self.width))
    self.y = 0 - self.height
    self.color = [1.0, 0.5, 0.5, 1.0]
    self.play(animation: :roll, loop: true)
    self.speed = 6
  end

  def move(enemies)
    self.y += self.speed
    if self.y > Window.height
      self.remove
      enemies.delete(self)
    end
  end
end
```

サイズが半分（15×15）で速さが2倍（6）、赤いティント、200点。小さくて当てにくいため高得点にしています。

### config.rb に require を追加する

config.rb

```ruby
require "./app/models/enemy_1"
require "./app/models/enemy_2"
require "./app/models/enemy_3"
```

### app/main.rb に Enemy3 のスポーンを追加する

Enemy3はスコアが300以上になってから出現します。

```ruby
enemies << Enemy1.new if tick % 20 == 0 && rand(0..2) == 0
enemies << Enemy2.new if tick % 30 == 0 && rand(0..2) == 0
enemies << Enemy3.new if @status.score >= 300 && tick % 25 == 0 && rand(0..2) == 0
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

スコアが300を超えると小さくて速い赤い敵が出現し始める。倒すと200点。

#### *ここで試したいこと

- Enemy3の `speed` を変えてみよう。速くしすぎると当たり判定が難しくなる。
- `SCORE` の値を変えて3種類の敵のバランスを調整してみよう。
- Enemy1・2・3のパラメータを比べてみよう。何が共通で何が違うか確認しよう。
