## {{ page.section_title }}

### ItemPowクラスを作る

`app/models/item_pow.rb` を新規作成しましょう。

app/models/item_pow.rb

```ruby
class ItemPow < Sprite
  attr_accessor :speed

  def initialize
    super("./app/images/item_pow.png",
      width: 30,
      height: 30
    )
    self.speed = 3
  end

  def move
    self.y += self.speed
  end

  def self.set(position, items)
    item = self.new
    item.x = position.first
    item.y = position.last
    items << item
  end
end
```

### config.rb に require を追加する

config.rb

```ruby
require "ruby2d"

set width: 600, height: 800

require "./app/messages/game_title"

```

### app/main.rb にアイテムの処理を追加する

app/main.rb（items を追加・update do の :start を更新）

```ruby
items = []

update do
  Star.set(stars) if tick % 10 == 0
  Star.move(stars)

  case @status.game_status
  when :title
  when :start
    fighter.opening_action
    Bullet.move(bullets)
    ItemPow.set([0, 0], items) if tick % 180 == 0
    items.each { |item| item.move }
  end
  tick += 1
end
```

`tick % 180 == 0` で約3秒に1回アイテムを出現させます。`[0, 0]` は位置（左上）の仮置きです。次のセクションでランダムに変更します。
