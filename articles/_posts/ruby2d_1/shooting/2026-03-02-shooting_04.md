## {{ page.section_title }}

### SpriteクラスとCircleクラスの違い

ヘビゲームでは `Circle` を使いましたが、シューティングゲームでは画像を使う `Sprite` クラスを使います。

| クラス | 描画方法 |
|--------|---------|
| Circle, Square など | コードで図形を描く |
| Sprite | 画像ファイルを読み込む |

### 画像の切り出し（clip）

`fighter.png` は1枚の画像の中に複数のコマが入っています。`clip_width` と `clip_height` で1コマのサイズを指定し、`clip_x` と `clip_y` でどのコマを表示するかを切り替えます。

### Fighterクラスを作る

`app/models/fighter.rb` を新規作成しましょう。

app/models/fighter.rb

```ruby
class Fighter < Sprite
  attr_accessor :speed, :status, :pow, :level, :life, :life_gauge

  def initialize
    super("app/images/fighter.png")
    self.width = 30
    self.height = 30
    self.clip_width = 15
    self.clip_height = 15
    self.speed = 3.0
    self.remove
    self.status = nil
    self.pow = 0
    self.level = 1
    self.life = 3
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end
end
```

`self.remove` で初期状態では画面に表示しないようにしています。

### config.rb と app/main.rb を更新する

config.rb

```ruby
require "ruby2d"

set width: 600, height: 800

require "./app/messages/game_title"
require "./app/status"
require "./app/models/fighter"
```

app/main.rb（スペースキーで自機を表示）

```ruby
require "./config"

@status = Status.new
fighter = Fighter.new
game_title = GameTitle.new

update do
  case @status.game_status
  when :title
  when :start
  end
end

on :key_down do |event|
  key = event.key
  case key
  when "space"
    if @status.game_status == :title
      game_title.remove
      @status.to_start
      fighter.x = (Window.width - fighter.width) / 2
      fighter.y = Window.height / 2
      fighter.add
    end
  end
end

show
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

スペースキーを押すと、画面中央に自機の画像が表示される。

#### *ここで試したいこと

- `width` と `height` の値を変えて自機のサイズを変えてみよう。
- `fighter.y` の初期位置を変えてみよう。
