### sin 関数で左右に揺らす

`Math.sin` は引数に渡した値に応じて -1.0 〜 1.0 の値を返します。この値に速さを掛けると、滑らかに左右に動かせます。

```
Math.sin(0)    → 0.0
Math.sin(1)    → 0.84
Math.sin(3.14) → 0.0
Math.sin(6.28) → 0.0  ← 一周して戻る
```

`tick` を少しずつ増やして `Math.sin(tick * 0.05)` にすると、ゆっくり左右に揺れます。

### Enemy2クラスを作る

`app/models/enemy_2.rb` を新規作成しましょう。

app/models/enemy_2.rb

```ruby
class Enemy2 < Sprite
  SCORE = 150
  attr_accessor :speed, :tick

  def initialize
    super("./app/images/enemy_1.png",
      width: 30,
      height: 30,
      animations: {
        roll: [
          { width: 15, height: 15, x: 0,  y: 0  },
          { width: 15, height: 15, x: 15, y: 0  },
          { width: 15, height: 15, x: 0,  y: 15 },
          { width: 15, height: 15, x: 15, y: 15 }
        ]
      }
    )
    self.x = rand(0..(Window.width - self.width))
    self.y = 0 - self.height
    self.color = [0.5, 0.8, 1.0, 1.0]
    self.play(animation: :roll, loop: true)
    self.speed = 2
    self.tick = 0
  end

  def move(enemies)
    self.y += self.speed
    self.x += Math.sin(self.tick * 0.05) * 4
    self.tick += 1
    if self.y > Window.height
      self.remove
      enemies.delete(self)
    end
  end
end
```

`self.color = [0.5, 0.8, 1.0, 1.0]` で画像を青くティントしています。スコアは150点です。

### config.rb に require を追加する

config.rb

```ruby
require "./app/models/enemy_1"
require "./app/models/enemy_2"
```

### app/main.rb に Enemy2 のスポーンを追加する

```ruby
enemies << Enemy1.new if tick % 20 == 0 && rand(0..2) == 0
enemies << Enemy2.new if tick % 30 == 0 && rand(0..2) == 0
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

青い敵がゆっくり左右に揺れながら下りてくる。Enemy1より遅いが倒すと150点。

#### *ここで試したいこと

- `tick * 0.05` の `0.05` を変えて揺れの速さを変えてみよう（大きいほど速く揺れる）。
- `* 4` の数字を変えて揺れの幅を変えてみよう。
