### パラメータ調整のポイント

ゲームとして面白くなるよう、以下の数値を調整してみましょう。

**難しすぎると感じたら**

```ruby
# 敵のスピードを下げる
self.speed = 2       # Enemy1（元：3）
self.speed = 5       # Enemy3（元：6）

# 無敵時間を長くする
INVINCIBLE_DURATION = 180  # 元：120（約3秒に）

# 難易度の上昇を緩やかにする
diff_level = @status.score / 800  # 元：500
```

**簡単すぎると感じたら**

```ruby
# 出現頻度を上げる
spawn_rate = [15 - diff_level * 2, 6].max  # 元：20から / 最短8

# ライフを減らす
self.life = 2  # 元：3
```

### 次のステップ

このゲームをさらに発展させるアイデアです。

- **CSVでステージ管理**: 敵の出現パターンをCSVファイルに書いて読み込む
- **ボスキャラクター**: HPを持つ大型の敵を作る
- **BGM・効果音**: ruby2d の `Sound` クラスを使う
- **パワーダウン**: 敵に当たるとレベルが下がる処理を `power_down` で実装する
