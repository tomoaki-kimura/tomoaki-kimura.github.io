### messages フォルダにクラスを作る

タイトル画面の文字を管理するクラスを `app/messages/` に作ります。

`app/messages/game_title.rb` を新規作成しましょう。

app/messages/game_title.rb

```ruby
class GameTitle
  attr_accessor :title, :start_message

  def initialize
    self.title = Text.new("Shooting", size: 60)
    self.title.x = (Window.width - self.title.width) / 2
    self.title.y = 300
    self.start_message = Text.new("press key 'space' to start", size: 40)
    self.start_message.x = (Window.width - self.start_message.width) / 2
    self.start_message.y = 450
  end

  def add
    self.title.add
    self.start_message.add
  end

  def remove
    self.title.remove
    self.start_message.remove
  end
end
```

`(Window.width - self.title.width) / 2` で、テキストを横方向に中央揃えしています。

### config.rb に require を追加する

作ったクラスを使うために、`config.rb` で読み込みます。

config.rb

```ruby
require "ruby2d"

set width: 600, height: 800

require "./app/messages/game_title"
```

### app/main.rb でタイトルを表示する

app/main.rb

```ruby
require "./config"

game_title = GameTitle.new

show
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

タイトルと「press key 'space' to start」が画面中央付近に表示される。

#### *ここで試したいこと

- タイトルの文字を変えてみよう。
- `size` を変えて文字の大きさを変えてみよう。
- `y` の値を変えて位置を上下させてみよう。
