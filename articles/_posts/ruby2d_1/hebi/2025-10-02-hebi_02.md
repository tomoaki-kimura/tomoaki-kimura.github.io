## {{ page.section_title }}

### 図形の描写

前回は描画のためのウインドウを立ち上げましたので、ウインドウをキャンバスとして図形を描画しましょう。

Circleクラスを使って半径10pxの丸を描きます。

main.rb
```
requie 'ruby2d'

Circle.new(radius: 10)

show
```

コードは書き換える度に実行しなおす必要がありますので、実行中の場合は必ず停止をしておきましょう。

停止を確認したら、以下のコマンドでファイルを実行します。

### ファイルの実行

bash
```
ruby2d/hebi $ ruby main.rb
```

### 結果

左上に丸が出現。

<img src="/assets/images/posts/ruby2d_1/hebi_0002.jpg" alt="ウインドウ左上に丸が出現する画像" class="w-full md:w-md">

#### `check point` ここで試したいこと

- 引数の数字を変更する。

`radius: 10` の数字部分を好きな数に変更してみましょう。

変化量に対してどのくらいの変化があるか確認してみてください。 

- 引数を省略する。

`(radius: 10)` の部分を削除してみましょう。

どのような結果になるか試してみてください。

##### `※ 試した後は忘れずにもとの値に戻しておきましょう。` 

### 丸の位置を変更する

次に、出現させた丸の位置を動的な数値に変更してみましょう。

コードの内容を以下のように変更します。

main.rb
```
requie 'ruby2d'

head = Circle.new(radius: 10)
head.x = Window.width / 2
head.y = Window.height / 2

show
```

では確認しましょう。

### ファイルの実行

bash
```
ruby2d/hebi $ ruby main.rb
```

### 結果

<img src="/assets/images/posts/ruby2d_1/hebi_0003.jpg" alt="ウインドウ中央に丸が出現する画像" class="w-full md:w-md">

丸が真ん中に移動しています。

`Window` は画面のことを指しますので、

#### `check point` ここで試したいこと

- `Window.width / 2` と `Window.height / 2` を `200` に置き換える。

- 他にも適当な数字を試してみる。

すると、ウインドウ上の座標の位置は、左上を基点として `左右` 方向を `X軸`, `上下` 方向を `Y軸` となっていることが分かります。
