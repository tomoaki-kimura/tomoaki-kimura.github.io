### キーイベントの取得

キーイベントは、キーボードを押した際の情報を取得するきっかけとなるイベントです。

主に使うものは、キーを操作する間「ずっと」反応する `on: key` と、押下時にのみ反応する `on: key_down` の２種類です。

他にも押している間のみの `key_held` や、キーを離す時のみの `key_up` などがあります。

今回のヘビゲームは、動くのは自動で、ボタンを押したときに舵を切るように進行方向を変えるイメージです。

なので、操作は連続的なものではなく、押下時のみの `on: key_down` を使います。

コードを以下のように追記しましょう。

main.rb
```
require "ruby2d"

head = Circle.new(radius: 10)
head.x = Window.width / 2
head.y = Window.height / 2

## 追記
on :key_down do |event|
  p event.key
end
## ここまで追記

show
```

### ファイルの実行

bash
```
$ ruby main.rb
```

### 結果

画面が立ち上がり、画面がアクティブの状態でキー操作をした時、押したキーがターミナルに出力されば成功です。

### イベントに動作を付加

次に、今回の操作で使う `←` と `→` キーを使って、表示されている `head` を動かしてみましょう。

main.rb
```
require "ruby2d"

head = Circle.new(radius: 10)
head.x = Window.width / 2
head.y = Window.height / 2

on :key_down do |event|
  if event.key == "right"
    head.x += 10
  elsif event.key == "left"
    head.x -= 10
  end
end

show
```

### ファイルの実行

bash
```
$ ruby main.rb
```

### 結果

ボタン押下で丸が移動します。

<img src="/assets/images/posts/ruby2d_1/hebi_0006.jpg" alt="ウインドウ左上に丸が出現する画像" class="w-full md:w-md">

### 継続的に移動する

main.rb
```
require "ruby2d"

head = Circle.new(radius: 10)
head.x = Window.width / 2
head.y = Window.height / 2
speed = 1
x_flug = true
y_flug = false

on :key_down do |event|
  if event.key == "right"
    x_flug = true
    y_flug = false
  elsif event.key == "left"
    x_flug = false
    y_flug = false
  end
end

update do
  if x_flug
    head.x += speed
  else
    head.x -= speed
  end
  if y_flug
    head.y += speed
  else
    head.y -= speed
  end
end

show
```

### ファイルの実行

bash
```
$ ruby main.rb
```

### 結果

自機がボタン左右で斜めに移動しながら上に移動。

#### *ここで試したいこと

- 再度移動スピードの数値を変更する。
