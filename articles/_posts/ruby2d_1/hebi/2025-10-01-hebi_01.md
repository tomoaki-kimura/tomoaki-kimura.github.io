## {{ page.section_title }}

### gem のインストール

基礎編を済ませていると、`ruby2d` はインストールされているはずですが、

もし、開発環境が変わったりしている場合は、再度2D描写用のライブラリをインストールしましょう。

インストールは、ターミナルから以下のコマンドを実行しましょう。

それぞれの環境のホームディレクトリからスタートとします。

```bash
$ gem install ruby2d
```

すると、以下のようなログが流れてインストールが完了します。

```bash
$ gem install ruby2d
Building native extensions. This could take a while...
Successfully installed ruby2d-0.12.1
Parsing documentation for ruby2d-0.12.1
Done installing documentation for ruby2d after 2 seconds
1 gem installed
```

次に、プロジェクトを作成します。ホームディレクトリから、

```bash
$ mkdir ruby2d
$ mkdir ruby2d/hebi
$ cd ruby2d/hebi
```

を実行して、`hebi` ディレクトリに入りましょう。

最後に、以下のコマンドでメインとなるファイルを作っておきましょう。

```
ruby2d/hebi $ touch main.rb 
```

`hebi` 直下に `main.rb` を作成されているはずです。

ここまでで今回の環境が整いましたので、VSCodeを開き直しておくと良いでしょう。

VSCodeが開きなおせたら、コーディングに進みます。

`main.rb` の内容を以下のように書きましょう。

### main.rb の作成

main.rb

```
requie "ruby2d"

show
```

### ファイルの実行

```bash
ruby2d/hebi $ ruby main.rb
```
