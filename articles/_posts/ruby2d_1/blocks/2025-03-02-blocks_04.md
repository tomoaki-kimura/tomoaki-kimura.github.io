## {{ page.section_title }}

### 発射フラグを作る

ボールが「発射済みか・待機中か」を管理する変数を作ります。このような `true` / `false` だけを持つ変数を**フラグ**と呼びます。

main.rb（変数を追加）

```ruby
is_move = false
```

### バーへの追従

`is_move` が `false` のとき、ボールをバーの上に固定します。

main.rb（`update do` を更新）

```ruby
update do
  if is_move
    ball.x += x_flag ? speed : -speed
    ball.y += y_flag ? speed : -speed

    y_flag = true  if ball.contains?(ball.x, 0)
    x_flag = true  if ball.contains?(0, ball.y)
    x_flag = false if ball.contains?(Window.width, ball.y)
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end
```

### スペースキーで発射する

main.rb（`on :key_down` を追加）

```ruby
on :key_down do |event|
  if event.key == "space" && !is_move
    is_move = true
  end
end
```

`on :key_down` はキーを押した**瞬間だけ**呼ばれます。`on :key` にすると押しっぱなしで連続して呼ばれます。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

最初はボールがバーの上に乗っている。スペースキーを押すと発射される。

#### *ここで試したいこと

- バーを動かしながらスペースを押して、発射位置が変わることを確認しよう。
- `on :key_down` を `on :key` に変えると何が起きるか試してみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2

x_flag = true
y_flag = false
speed = 5
is_move = false

on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end

on :key_down do |event|
  if event.key == "space" && !is_move
    is_move = true
  end
end

update do
  if is_move
    ball.x += x_flag ? speed : -speed
    ball.y += y_flag ? speed : -speed

    y_flag = true  if ball.contains?(ball.x, 0)
    x_flag = true  if ball.contains?(0, ball.y)
    x_flag = false if ball.contains?(Window.width, ball.y)
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end

show
```
