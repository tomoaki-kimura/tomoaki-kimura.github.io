## {{ page.section_title }}

### ファイルの作成

ターミナルで以下を実行して、`blocks` ディレクトリと `main.rb` を作ります。

```bash
$ mkdir ruby2d/blocks
$ cd ruby2d/blocks
ruby2d/blocks $ touch main.rb
```

### バーを表示する

`Rectangle` クラスを使ってバーを表示します。

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

show
```

`(Window.width - bar.width) / 2` でバーを横方向に中央に配置しています。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ウィンドウが立ち上がり、画面下部にバーが表示される。

#### *ここで試したいこと

- `width` と `height` を変えてバーの大きさを変えてみよう。
- `bar.y` の値を変えてバーの位置を上下させてみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

show
```
