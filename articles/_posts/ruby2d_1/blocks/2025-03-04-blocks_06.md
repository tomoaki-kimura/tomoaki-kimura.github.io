## {{ page.section_title }}

### なぜクラスにするのか

今 `main.rb` にはバー・ボール・ブロックの処理がすべて混在しています。登場するものが増えるほど読みにくくなるため、それぞれの「もの」をクラスとして整理します。

### Barクラスを作る

まず `main.rb` の中にクラスを書いてみましょう。

main.rb（先頭に追加）

```ruby
class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end
end
```

- `class Bar < Rectangle` — `Rectangle` を継承した `Bar` クラスを作ります
- `attr_accessor :speed` — `speed` を読み書きできるようにします
- `def initialize` — `Bar.new` したときに自動で呼ばれるメソッドです
- `super` — 親クラス（`Rectangle`）の `initialize` を呼びます

### main.rb の bar をクラスに切り替える

これまで `Rectangle.new(...)` で作っていた部分を `Bar.new` に変えます。

main.rb

```ruby
bar = Bar.new
```

バーの初期設定は `initialize` に移ったので、`main.rb` 側の設定コードは削除します。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

見た目は変わらない。クラスを使っても同じように動くことを確認しよう。

#### *ここで試したいこと

- `bar.speed` の値を変えてみよう（`attr_accessor` があるので `bar.speed = 10` のように書ける）。
- `Bar.new` の前後に `p bar.speed` を入れて値が入っているか確認しよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end
end

bar = Bar.new

ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2

x_flag = true
y_flag = false
speed = 5
is_move = false

on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end

on :key_down do |event|
  if event.key == "space" && !is_move
    is_move = true
  end
end

update do
  if is_move
    ball.x += x_flag ? speed : -speed
    ball.y += y_flag ? speed : -speed

    y_flag = true  if ball.contains?(ball.x, 0)
    x_flag = true  if ball.contains?(0, ball.y)
    x_flag = false if ball.contains?(Window.width, ball.y)

    if ball.y > Window.height
      is_move = false
      x_flag = true
      y_flag = false
    end
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end

show
```
