## {{ page.section_title }}

### Ballクラスを作る

`Bar` と同じように `Ball` クラスを作ります。フラグと速度も `initialize` に移動します。

main.rb（`Bar` クラスの下に追加）

```ruby
class Ball < Circle
  attr_accessor :x_flag, :y_flag, :speed, :is_move

  def initialize
    super(radius: 10)
    self.speed  = 5
    self.x_flag = true
    self.y_flag = false
    self.is_move = false
    self.x = Window.width / 2
    self.y = Window.height / 2
  end
end
```

- `super(radius: 10)` — 親クラス `Circle` の `initialize` に `radius: 10` を渡します
- フラグ（`x_flag`・`y_flag`・`is_move`）を `attr_accessor` で管理します

### main.rb の ball 生成を切り替える

main.rb

```ruby
ball = Ball.new
```

`ball.x`・`ball.y`・`x_flag`・`y_flag`・`speed`・`is_move` のべた書きはすべて削除します。

### フラグの参照先を変える

`update do` と `on :key_down` の中のフラグ変数を `ball.x_flag`・`ball.y_flag`・`ball.is_move` に変えます。

main.rb（`on :key_down` を更新）

```ruby
on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end
```

main.rb（`update do` を更新）

```ruby
update do
  if ball.is_move
    ball.x += ball.x_flag ? ball.speed : -ball.speed
    ball.y += ball.y_flag ? ball.speed : -ball.speed

    ball.y_flag = true  if ball.contains?(ball.x, 0)
    ball.x_flag = true  if ball.contains?(0, ball.y)
    ball.x_flag = false if ball.contains?(Window.width, ball.y)

    if ball.y > Window.height
      ball.is_move = false
      ball.x_flag = true
      ball.y_flag = false
    end
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

動きは変わらない。ボールの状態がすべて `ball.xxx` でアクセスできるようになった。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end

  def move(event)
    if event.key == "left"
      self.x -= self.speed
    end
    if event.key == "right"
      self.x += self.speed
    end
    limit
  end

  private

  def limit
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end

class Ball < Circle
  attr_accessor :x_flag, :y_flag, :speed, :is_move

  def initialize
    super(radius: 10)
    self.speed   = 5
    self.x_flag  = true
    self.y_flag  = false
    self.is_move = false
    self.x = Window.width / 2
    self.y = Window.height / 2
  end
end

bar  = Bar.new
ball = Ball.new

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  if ball.is_move
    ball.x += ball.x_flag ? ball.speed : -ball.speed
    ball.y += ball.y_flag ? ball.speed : -ball.speed

    ball.y_flag = true  if ball.contains?(ball.x, 0)
    ball.x_flag = true  if ball.contains?(0, ball.y)
    ball.x_flag = false if ball.contains?(Window.width, ball.y)

    if ball.y > Window.height
      ball.is_move = false
      ball.x_flag = true
      ball.y_flag = false
    end
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end

show
```
