## {{ page.section_title }}

### バーへの当たり判定を追加する

ボールがバーに当たったら `y_flag` を反転させます。`Ball#move` の中の `reflect_wall` の次に呼ぶようにします。

app/ball.rb（`move` メソッドを更新）

```ruby
def move(bar)
  if self.is_move
    self.x += self.x_flag ? self.speed : -self.speed
    self.y += self.y_flag ? self.speed : -self.speed
    reflect_wall
    refrect(bar)
    fall_down
  else
    follow(bar)
  end
end
```

### refrect メソッドを追加する

バーの上面に当たったとき（ボールが下から当たったとき）だけ反射します。

app/ball.rb（`private` の中に追加）

```ruby
def refrect(bar)
  if bar.contains?(self.x, self.y + self.radius) && self.y_flag
    self.y_flag = false
  end
end
```

- `bar.contains?(self.x, self.y + self.radius)` — ボールの底がバーの範囲内にあるか
- `&& self.y_flag` — 下方向に動いているときだけ反射する（上からすり抜けないように）

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ボールがバーに当たると跳ね返るようになった。バーを動かしてボールを打ち返せる。

#### *ここで試したいこと

- `&& self.y_flag` を消すと何が起きるか試してみよう（バーをすり抜けることがある）。
- バーの端で打つとボールの角度が変わるか試してみよう（変わらない。変化させる改造は後のセクションで）。

### ここまでのコード

app/ball.rb

```ruby
class Ball < Circle
  attr_accessor :x_flag, :y_flag, :speed, :is_move

  def initialize
    super(radius: 10)
    self.speed   = 5
    self.x_flag  = true
    self.y_flag  = false
    self.is_move = false
    self.x = Window.width / 2
    self.y = Window.height / 2
  end

  def move(bar)
    if self.is_move
      self.x += self.x_flag ? self.speed : -self.speed
      self.y += self.y_flag ? self.speed : -self.speed
      reflect_wall
      refrect(bar)
      fall_down
    else
      follow(bar)
    end
  end

  private

  def reflect_wall
    self.y_flag = true  if self.contains?(self.x, 0)
    self.x_flag = true  if self.contains?(0, self.y)
    self.x_flag = false if self.contains?(Window.width, self.y)
  end

  def refrect(bar)
    if bar.contains?(self.x, self.y + self.radius) && self.y_flag
      self.y_flag = false
    end
  end

  def follow(bar)
    self.x = bar.x + bar.width / 2
    self.y = bar.y - self.radius
  end

  def fall_down
    if self.y > Window.height
      self.is_move = false
      self.x_flag  = true
      self.y_flag  = false
    end
  end
end
```

main.rb（変更なし）

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"

bar  = Bar.new
ball = Ball.new

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
end

show
```
