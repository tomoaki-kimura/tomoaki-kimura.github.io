## {{ page.section_title }}

### on :key でキー入力を受け取る

`on :key` はキーを**押している間、毎フレーム**呼ばれます。

main.rb

```ruby
on :key do |event|
  if event.key == "left"
    bar.x -= 5
  end
  if event.key == "right"
    bar.x += 5
  end
end
```

### はみ出し制限を追加する

このままだと画面の外にはみ出てしまうので、制限を加えます。

main.rb（`on :key` の中を更新）

```ruby
on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

左右キーでバーが動き、画面の端で止まる。

#### *ここで試したいこと

- `5` を変えてバーの速さを変えてみよう。
- はみ出し制限を外すと何が起きるか試してみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end

show
```
