### ファイルを作る

```bash
ruby2d/blocks $ touch app/block.rb
```

### ウィンドウサイズを設定する

ブロックを9列並べるためにウィンドウサイズを指定します。`require "ruby2d"` の直後に書きます。

main.rb（追加）

```ruby
set width: 800, height: 600
```

### Blockクラスを作る

app/block.rb

```ruby
class Block < Rectangle
  BLOCK_COLORS = %w(
    red
    orange
    yellow
    green
    blue
    fuchsia
    purple
  )

  def initialize
    super(width: 80, height: 25)
    self.x = self.width / 2
    self.y = self.height * 2
  end

  def self.set_blocks
    BLOCK_COLORS.map.with_index(0) do |color, r|
      9.times.map do |c|
        block = self.new
        block.color = color
        block.x += block.width * c
        block.y += block.height * r
        block.width  -= 1
        block.height -= 1
        block
      end
    end.flatten
  end
end
```

- `BLOCK_COLORS` — クラス定数です。`%w(...)` で文字列の配列を作ります
- `self.set_blocks` — `Block.set_blocks` のように呼ぶクラスメソッドです
- `BLOCK_COLORS.map.with_index(0)` — 色のインデックスを行番号 `r` として使います
- `block.width -= 1` — ブロック間に1ピクセルの隙間を作ります

### main.rb に追加する

main.rb

```ruby
require_relative "app/block"

blocks = Block.set_blocks
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

```ruby
  BLOCK_COLORS = %w(
    red

```

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
require_relative "app/block"

set width: 800, height: 600

bar    = Bar.new
ball   = Ball.new
blocks = Block.set_blocks

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
end

show
```
