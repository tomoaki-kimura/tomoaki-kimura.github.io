### 自機用のファイルを作成

今回は、ヘビの時と違って、画面に出現する要素が「自分」「ボール」「沢山のブロック」というように、多くの変数と処理が発生する事が考えられます。

こういった場合、メンテナンスの観点から、単一のファイルのすべての処理を書くより、それぞれのキャラクター毎にファイルを分けておきたいところです。

では、実際に先程作ったバーを別のファイルに分離し、main.rbと連携させてみましょう。

以下コマンドで、`bar.rb` を作成します。

```bash
ruby2d/blocks $ touch bar.rb
```

VSCodeで開いて、以下のように書いてみましょう。



```
$ mkdir ruby2d
$ mkdir ruby2d/blocks
$ cd ruby2d/blocks
```

を実行して、`blocks` ディレクトリに入りましょう。

最後に、以下のコマンドでメインとなるファイルを作っておきましょう。

```
ruby2d/blocks $ touch main.rb 
```

`blocks` 直下に `main.rb` を作成されているはずです。

ここまでで今回の環境が整いましたので、VSCodeを開き直しておくと良いでしょう。

VSCodeが開きなおせたら、コーディングに進みます。

`main.rb` の内容を以下のように書きましょう。

### main.rb の作成

main.rb

```
requie "ruby2d"

show
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

NativeWindowが立ち上がればOK。
