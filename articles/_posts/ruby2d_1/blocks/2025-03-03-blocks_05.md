## {{ page.section_title }}

### 落下判定を追加する

ボールの `y` が画面の高さを超えたら落下とみなし、`is_move` を `false` に戻します。

main.rb（`update do` の `if is_move` の中に追加）

```ruby
if ball.y > Window.height
  is_move = false
  x_flag = true
  y_flag = false
end
```

`x_flag` と `y_flag` もリセットして、次の発射で同じ方向から始まるようにします。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ボールが画面下に落ちるとバーの上に戻り、スペースで再発射できる。

これでブロック崩しの基本的な動きが完成しました。

#### *ここで試したいこと

- わざとボールを落として、バーに戻ることを確認しよう。
- リセット後にバーを動かしてからスペースで発射してみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2

x_flag = true
y_flag = false
speed = 5
is_move = false

on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end

on :key_down do |event|
  if event.key == "space" && !is_move
    is_move = true
  end
end

update do
  if is_move
    ball.x += x_flag ? speed : -speed
    ball.y += y_flag ? speed : -speed

    y_flag = true  if ball.contains?(ball.x, 0)
    x_flag = true  if ball.contains?(0, ball.y)
    x_flag = false if ball.contains?(Window.width, ball.y)

    if ball.y > Window.height
      is_move = false
      x_flag = true
      y_flag = false
    end
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end

show
```
