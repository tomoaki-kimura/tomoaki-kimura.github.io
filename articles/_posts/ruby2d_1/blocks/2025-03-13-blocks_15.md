## {{ page.section_title }}

### スコア変数とテキストを作る

main.rb（`blocks = Block.set_blocks` の下に追加）

```ruby
score = 0
score_text = Text.new("Score: 0", x: 10, y: 10, size: 20)
```

### ブロックを壊したときにスコアを加算する

`broken_by` に `score` を渡してブロックを壊すたびに加算します。

main.rb（`update do` を更新）

```ruby
update do
  ball.move(bar)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
end
```

`Block.broken_by` がスコアの増分（壊した枚数）を返すように変更します。

### broken_by の戻り値を変更する

app/block.rb（`self.broken_by` を更新）

```ruby
def self.broken_by(ball, blocks)
  point = 0
  blocks.each do |block|
    point += 1 if block.refrect(ball, blocks)
  end
  point
end
```

`refrect` が当たったときに `true` を返すので、`point` を1ずつ増やして返します。

### refrect の戻り値を整理する

`refrect` は当たった場合に `true` 相当の値を返しています。各 `private` メソッドもブロックを消したとき（条件が成立したとき）に `truthy` な値（`blocks.delete(self)` の戻り値）を返すため、変更は不要です。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ブロックを壊すたびに画面左上のスコアが増える。

#### *ここで試したいこと

- スコアの文字サイズや色を変えてみよう（`size:` や `color:` オプション）。
- 1ブロックの得点を10点にしてみよう（`point += 10`）。

### ここまでのコード

app/block.rb（`self.broken_by` のみ変更）

```ruby
def self.broken_by(ball, blocks)
  point = 0
  blocks.each do |block|
    point += 1 if block.refrect(ball, blocks)
  end
  point
end
```

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
require_relative "app/block"

set width: 800, height: 600

bar    = Bar.new
ball   = Ball.new
blocks = Block.set_blocks
score  = 0
score_text = Text.new("Score: 0", x: 10, y: 10, size: 20)

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
end

show
```
