### Bundlerとは

プロジェクトが大きくなると、使うgemの数も増えていきます。「このプロジェクトはrakeとrspecを使う」「あのプロジェクトはrailsを使う」というように、プロジェクトごとに必要なgemの組み合わせをまとめて管理してくれるのがBundlerです。

### Bundlerをインストールする

Bundlerもgemの1つなので、`gem install` で入れられます。

```bash
$ gem install bundler
```

確認します。

```bash
$ bundle --version
Bundler version 2.x.x
```

### Gemfileを作る

適当なフォルダを作って移動し、`bundle init` を実行します。

```bash
$ mkdir sample_gems
$ cd sample_gems
sample_gems $ bundle init
```

`Gemfile` というファイルが作られます。中身を見てみましょう。

```ruby
# frozen_string_literal: true

source "https://rubygems.org"

# gem "rails"
```

`source` は、gemをどこから取得するかの指定です。`# gem "rails"` はコメントアウトされたサンプルで、ここに使いたいgemを書いていきます。

### gemを追記する

`rake` を使いたい場合、以下の行を追加します。

```ruby
gem "rake"
```

Gemfileは「このプロジェクトで使うgemのリスト」だと考えるとイメージしやすいです。
