## {{ page.section_title }}

### gemとは

Rubyでは、他の人が作った便利な機能（ライブラリ）を「gem」という単位で公開・配布しています。ここまでのカリキュラムで使ってきた `ruby2d` も、実はgemの1つです。

```bash
$ gem install ruby2d
```

このコマンドで、`ruby2d` というgemをインストールしていました。

### RubyGemsとは

RubyGemsは、この「gem」を管理するための仕組み・コマンドのことです。Rubyをインストールすると、一緒に `gem` コマンドが使えるようになっています。

```bash
$ gem --version
3.x.x
```

### gemをインストールする

`gem install` で、単体のgemをインストールできます。例えば `rake` というタスク実行用のgemを入れてみます。

```bash
$ gem install rake
```

### インストール済みのgemを確認する

```bash
$ gem list
```

これまでにインストールしたgemの一覧が表示されます。

#### *ここで試したいこと

- `gem list` の中に `ruby2d` があるか探してみよう。
