### メソッドを定義する

`puts` や `.times` のように、これまで使ってきた「〇〇する」という命令はすべてメソッドです。`def` を使うと、自分だけのメソッドを作れます。

```ruby
irb(main):001> def greet
irb(main):002>   puts "こんにちは"
irb(main):003> end
=> :greet
irb(main):004> greet
こんにちは
=> nil
```

`def メソッド名 ... end` でメソッドを定義し、`メソッド名` と書くだけで呼び出せます。

### 引数を受け取る

メソッドに値を渡したいときは、引数を使います。

```ruby
irb(main):001> def greet(name)
irb(main):002>   puts "こんにちは、#{name}さん"
irb(main):003> end
=> :greet
irb(main):004> greet("たろう")
こんにちは、たろうさん
=> nil
```

`greet(name)` の `name` が引数です。呼び出すときに渡した値（`"たろう"`）が `name` に入ります。

### 戻り値

メソッドは、最後に評価した式の値を自動的に返します。これを戻り値といいます。

```ruby
irb(main):001> def add(a, b)
irb(main):002>   a + b
irb(main):003> end
=> :add
irb(main):004> add(3, 5)
=> 8
```

`add` メソッドは最後に `a + b` を評価しているので、その結果（`8`）が戻り値になります。`return` を書いて明示的に返すこともできますが、最後の式が自動で返るので、多くの場合は省略できます。

Ruby2Dのゲームでも、以下のように当たり判定などの処理をメソッドにまとめていました。

```ruby
def hit(head)
  top = head.contains?(head.x, 0)
  bottom = head.contains?(head.x, Window.height)
  top || bottom
end
```

`hit(head)` の戻り値（`true`/`false`）を使って、`if hit(head)` のように条件分岐していたわけです。
