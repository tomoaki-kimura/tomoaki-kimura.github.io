### irbを起動する

`irb`（Interactive Ruby）は、Rubyのコードを1行ずつ試しながら実行できるツールです。ターミナルで以下を実行しましょう。

```bash
$ irb
irb(main):001>
```

こうなれば起動できています。ここにRubyのコードを書いてEnterを押すと、その場で実行されます。終了するときは `exit` と入力します。

### puts で出力する

`puts` は、文字列や数値を画面に表示するためのメソッドです。

```ruby
irb(main):001> puts "こんにちは"
こんにちは
=> nil
```

`こんにちは` が出力の内容、`=> nil` は `puts` というメソッド自体が返した値です。`puts` は「表示すること」が仕事なので、返す値は常に `nil`（何もないことを表すRubyの値）になります。

### p で出力する

`p` も出力用のメソッドですが、`puts` と少し挙動が違います。

```ruby
irb(main):001> p "こんにちは"
"こんにちは"
=> "こんにちは"
```

`p` は文字列を `"` で囲んだまま表示し、渡した値そのものを返します。デバッグ（コードの動作確認）でよく使われます。

#### *ここで試したいこと

- `puts 1 + 1` と `p 1 + 1` を両方試して、出力の違いを比べてみよう。
