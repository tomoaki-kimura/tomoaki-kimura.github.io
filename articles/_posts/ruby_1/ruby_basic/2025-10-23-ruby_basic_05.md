### ハッシュを作る

配列は「番号」で値を管理しますが、ハッシュは「名前（キー）」で値を管理します。`{}` の中に `キー => 値` を並べて作ります。

```ruby
irb(main):001> person = { "name" => "たろう", "age" => 10 }
=> {"name"=>"たろう", "age"=>10}
irb(main):002> person["name"]
=> "たろう"
```

### シンボルをキーにする

Rubyでは `"name"` のような文字列の代わりに、`:name` のようなシンボルをキーによく使います。シンボルは先頭に `:` をつけた、名前をつけるための専用の値です。

```ruby
irb(main):001> person = { name: "たろう", age: 10 }
=> {:name=>"たろう", :age=>10}
irb(main):002> person[:name]
=> "たろう"
```

`{ name: "たろう" }` は `{ :name => "たろう" }` の省略形です。

### 実はもう使っている

Ruby2Dのコードで書いていた、以下のような部分を覚えていますか。

```ruby
Circle.new(radius: 10)
```

これは実は、`radius: 10` という**ハッシュ**を `Circle.new` というメソッドに渡しているだけです。`radius:` がキー、`10` が値になっています。当時は気づかずに使っていましたが、正体はハッシュだったのです。
