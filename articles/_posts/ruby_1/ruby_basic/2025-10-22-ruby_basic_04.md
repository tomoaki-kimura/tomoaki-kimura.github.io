### 配列を作る

複数の値を1つにまとめておけるものを配列といいます。`[]` の中にカンマ区切りで値を並べて作ります。

```ruby
irb(main):001> fruits = ["りんご", "みかん", "ぶどう"]
=> ["りんご", "みかん", "ぶどう"]
```

### 要素を取り出す

`[番号]` で、配列の中の値を1つ取り出せます。番号は `0` から始まります。

```ruby
irb(main):001> fruits[0]
=> "りんご"
irb(main):002> fruits[1]
=> "みかん"
```

### 要素を追加する

`<<` や `push` で、配列の最後に値を追加できます。

```ruby
irb(main):001> fruits << "メロン"
=> ["りんご", "みかん", "ぶどう", "メロン"]
irb(main):002> fruits.push("いちご")
=> ["りんご", "みかん", "ぶどう", "メロン", "いちご"]
```

### よく使う配列のメソッド

```ruby
irb(main):001> fruits.length
=> 5
irb(main):002> fruits.first
=> "りんご"
irb(main):003> fruits.last
=> "いちご"
irb(main):004> fruits.include?("メロン")
=> true
```

`.length` は要素の数、`.first`/`.last` は最初/最後の要素、`.include?` はその値が含まれているかを `true`/`false` で返します。
