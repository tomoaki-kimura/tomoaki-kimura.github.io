### 変数に値を入れる

`=` を使うと、値に名前をつけて後から使い回せます。これを変数といいます。

```ruby
irb(main):001> name = "たろう"
=> "たろう"
irb(main):002> puts name
たろう
=> nil
```

`name` という変数に `"たろう"` という文字列を入れ、後から `name` と書くだけで中身を取り出せます。

### 数値

Rubyには整数（Integer）と小数（Float）があります。

```ruby
irb(main):001> age = 10
=> 10
irb(main):002> height = 1.4
=> 1.4
```

四則演算もそのまま書けます。

```ruby
irb(main):001> 3 + 2
=> 5
irb(main):002> 3 - 2
=> 1
irb(main):003> 3 * 2
=> 6
irb(main):004> 7 / 2
=> 3
irb(main):005> 7 % 2
=> 1
```

`/` は割り算ですが、整数同士だと小数点以下が切り捨てられます。`%` はあまりを求める演算子です。

### 真偽値

`true`（正しい）と `false`（正しくない）の2つの値があります。条件分岐などで使います。

```ruby
irb(main):001> is_sunny = true
=> true
```

### nil

`nil` は「何もない」ことを表す特別な値です。

```ruby
irb(main):001> nothing = nil
=> nil
```
