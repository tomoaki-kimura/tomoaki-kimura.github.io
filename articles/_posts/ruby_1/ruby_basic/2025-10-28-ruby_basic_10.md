### 比較演算子

条件分岐の中でよく使う、値を比較するための記号（比較演算子）をまとめます。

```ruby
irb(main):001> 3 == 3
=> true
irb(main):002> 3 != 4
=> true
irb(main):003> 3 > 2
=> true
irb(main):004> 3 < 2
=> false
irb(main):005> 3 >= 3
=> true
irb(main):006> 3 <= 2
=> false
```

`==` は「等しいか」、`!=` は「等しくないか」、`>` `<` `>=` `<=` はそれぞれ「より大きい」「より小さい」「以上」「以下」です。`=` 1つの代入と `==` の比較を間違えないように気をつけましょう。

### unless で「〜でなければ」を書く

`unless` は `if` の逆で、「もし〜でなければ」という条件です。

```ruby
irb(main):001> age = 8
=> 8
irb(main):002> unless age >= 10
irb(main):003*   puts "10歳未満です"
irb(main):004> end
10歳未満です
=> nil
```

`unless age >= 10` は `if age < 10` とほぼ同じ意味です。否定形の条件が1つだけのときに使うと読みやすくなります。

### && と || で条件を組み合わせる

`&&`（かつ）は両方とも `true` のとき、`||`（または）はどちらか一方でも `true` のときに全体が `true` になります。

```ruby
irb(main):001> age = 10
=> 10
irb(main):002> age >= 6 && age <= 12
=> true
irb(main):003> age == 5 || age == 10
=> true
```

Ruby2Dのコードでも、たとえばキー入力の判定で以下のように使われていました。

```ruby
if event.key == "right" || event.key == "left"
  # 右か左のキーが押されたときの処理
end
```

「右キー、または左キーが押されたら」という条件を `||` で表しています。
