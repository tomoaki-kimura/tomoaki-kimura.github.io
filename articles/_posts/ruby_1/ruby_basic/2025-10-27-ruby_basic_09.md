## {{ page.section_title }}

### if で条件によって処理を変える

`if` を使うと、「もし〜なら」という条件分岐が書けます。

```ruby
irb(main):001> age = 10
=> 10
irb(main):002> if age >= 10
irb(main):003*   puts "10歳以上です"
irb(main):004> end
10歳以上です
=> nil
```

### elseで、それ以外の場合を書く

条件に合わなかったときの処理は `else` に書きます。

```ruby
irb(main):001> age = 8
=> 8
irb(main):002> if age >= 10
irb(main):003*   puts "10歳以上です"
irb(main):004> else
irb(main):005*   puts "10歳未満です"
irb(main):006> end
10歳未満です
=> nil
```

### elsifで、条件を追加する

条件を複数に分けたいときは `elsif` を使います。

```ruby
irb(main):001> age = 15
=> 15
irb(main):002> if age < 6
irb(main):003*   puts "幼児です"
irb(main):004> elsif age < 13
irb(main):005*   puts "小学生です"
irb(main):006> elsif age < 16
irb(main):007*   puts "中学生です"
irb(main):008> else
irb(main):009*   puts "それ以外です"
irb(main):010> end
中学生です
=> nil
```

上から順番に条件を確認していき、最初に `true` になったものだけが実行されます。
