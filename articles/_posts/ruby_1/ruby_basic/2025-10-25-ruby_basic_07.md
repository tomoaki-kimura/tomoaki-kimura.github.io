### each で配列を1つずつ処理する

配列の中身を1つずつ順番に取り出して処理したいときは `each` を使います。

```ruby
irb(main):001> fruits = ["りんご", "みかん", "ぶどう"]
=> ["りんご", "みかん", "ぶどう"]
irb(main):002> fruits.each do |fruit|
irb(main):003*   puts fruit
irb(main):004> end
りんご
みかん
ぶどう
=> ["りんご", "みかん", "ぶどう"]
```

`fruits.each do |fruit| ... end` で、配列 `fruits` の要素が1つずつ `fruit` に入り、ブロックの中身が要素の数だけくり返されます。`times` が「回数」で繰り返すのに対して、`each` は「配列の中身」で繰り返す、という違いがあります。

### インデックスも一緒に取り出す

`each_with_index` を使うと、要素と一緒に番号（インデックス）も取り出せます。

```ruby
irb(main):001> fruits.each_with_index do |fruit, i|
irb(main):002*   puts "#{i}番目: #{fruit}"
irb(main):003> end
0番目: りんご
1番目: みかん
2番目: ぶどう
=> ["りんご", "みかん", "ぶどう"]
```
