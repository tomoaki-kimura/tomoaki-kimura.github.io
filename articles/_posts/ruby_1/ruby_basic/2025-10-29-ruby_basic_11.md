### case で値ごとに処理を分ける

1つの値が「どれに当てはまるか」で処理を分けたいときは、`if`/`elsif` を並べるより `case`/`when` を使うほうがすっきり書けます。

```ruby
irb(main):001> key = "right"
=> "right"
irb(main):002> case key
irb(main):003> when "right"
irb(main):004*   puts "右に動く"
irb(main):005> when "left"
irb(main):006*   puts "左に動く"
irb(main):007> else
irb(main):008*   puts "何もしない"
irb(main):009> end
右に動く
=> nil
```

`case key` の `key` の値が、`when` に書かれたどれかと一致すれば、その処理が実行されます。どれにも一致しなければ `else` が実行されます。

これを `if`/`elsif` で書くと以下のようになりますが、`case` のほうが「`key` の値で分岐している」ことが一目でわかります。

```ruby
if key == "right"
  puts "右に動く"
elsif key == "left"
  puts "左に動く"
else
  puts "何もしない"
end
```

Ruby2Dのゲームのキー操作でも、この `case event.key` という書き方がよく登場していました。

#### *ここで試したいこと

- `key` の値を `"left"` や、`"right"`/`"left"` 以外の文字に変えて、動きの違いを確認してみよう。
