### while で条件が続く限りくり返す

`times` は回数、`each` は配列の中身で繰り返しましたが、「ある条件が `true` の間だけくり返したい」ときは `while` を使います。

```ruby
irb(main):001> count = 0
=> 0
irb(main):002> while count < 3
irb(main):003*   puts count
irb(main):004>   count += 1
irb(main):005> end
0
1
2
=> nil
```

`count < 3` が `true` の間だけ、中の処理がくり返されます。`count += 1` を書き忘れると、条件がずっと `true` のままになり、処理が止まらなくなってしまう（無限ループ）ので注意しましょう。

### until で条件が満たされるまでくり返す

`until` は `while` の逆で、「条件が `false` の間だけ」くり返します。

```ruby
irb(main):001> count = 0
=> 0
irb(main):002> until count >= 3
irb(main):003*   puts count
irb(main):004>   count += 1
irb(main):005> end
0
1
2
=> nil
```

`while count < 3` と `until count >= 3` は、同じ結果になります。読みやすいと感じるほうを使って構いません。

なお、Ruby2Dのゲームでは、`while`/`until` の代わりに `update do ... end`（画面が描画されるたびにくり返される）という仕組みを使っていました。考え方は近いものです。
