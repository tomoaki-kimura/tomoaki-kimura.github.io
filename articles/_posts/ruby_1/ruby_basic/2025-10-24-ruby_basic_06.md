### times で決まった回数くり返す

同じ処理を何度もくり返したいときは、繰り返し構文を使います。まずは決まった回数だけくり返す `times` です。

```ruby
irb(main):001> 3.times do |i|
irb(main):002*   puts i
irb(main):003> end
0
1
2
=> 3
```

`3.times do |i| ... end` で、`{}` の代わりに `do` 〜 `end` の中身が3回くり返されます。`i` には、1回目は `0`、2回目は `1`、3回目は `2` と、実行回数（0から始まる）が順番に入ります。

### do 〜 end はブロックと呼ばれる

`do |i| ... end` のかたまりはブロックと呼ばれ、`.times` のようなメソッドに「くり返す処理そのもの」を渡すための書き方です。`|i|` の部分はブロック引数と呼ばれ、メソッド側から渡された値を受け取ります。

ブロックが1行で収まる場合は `{}` で書くこともできます。

```ruby
irb(main):001> 3.times { |i| puts i }
0
1
2
=> 3
```

#### *ここで試したいこと

- `3.times` の `3` を `5` に変えて、くり返す回数を変えてみよう。
- `puts i` を `puts i * 2` に変えて、出力される値を変えてみよう。
