### 文字列をつなげる

`+` で文字列同士をつなげられます。

```ruby
irb(main):001> "こんにちは" + "、たろうくん"
=> "こんにちは、たろうくん"
```

### 式展開を使う

文字列の中に `#{}` を書くと、その中のRubyのコードが実行されて文字列に埋め込まれます。これを式展開といいます。

```ruby
irb(main):001> name = "たろう"
=> "たろう"
irb(main):002> "こんにちは、#{name}くん"
=> "こんにちは、たろうくん"
```

`+` でつなげるより、`#{}` を使うほうが読みやすいことが多いです。数値を混ぜることもできます。

```ruby
irb(main):001> age = 10
=> 10
irb(main):002> "#{name}くんは#{age}歳です"
=> "たろうくんは10歳です"
```

`+` の場合、数値をそのままつなげようとするとエラーになりますが、式展開なら気にせず埋め込めます。

### よく使う文字列のメソッド

```ruby
irb(main):001> "ruby".length
=> 4
irb(main):002> "ruby".upcase
=> "RUBY"
```

`.length` で文字数、`.upcase` で大文字に変換できます。

#### *ここで試したいこと

- `"ruby".upcase` の逆に、大文字を小文字にする `.downcase` も試してみよう。
