### リポジトリとは

Gitでファイルの変更履歴を記録する対象のフォルダを、リポジトリと呼びます。フォルダの中に `.git` という特別なフォルダを作ることで、そのフォルダがリポジトリになります。

### リポジトリを作る

適当なフォルダを作って、そこに移動します。

```bash
$ mkdir sample_app
$ cd sample_app
```

`git init` を実行すると、このフォルダがリポジトリになります。

```bash
sample_app $ git init
Initialized empty Git repository in .../sample_app/.git/
```

### ファイルを作って状態を確認する

適当なファイルを1つ作ってみます。

```bash
sample_app $ touch main.rb
```

`git status` で、現在のリポジトリの状態を確認できます。

```bash
sample_app $ git status
On branch main

No commits yet

Untracked files:
  (use "git add <file>..." to include in what will be committed)
	main.rb
```

`Untracked files` に `main.rb` があります。これは「Gitがまだこのファイルの変更を記録していない」という意味です。次のセクションで、このファイルの変更を記録していきます。

#### *ここで試したいこと

- もう1つ別のファイルを作って、`git status` の表示がどう変わるか確認してみよう。
