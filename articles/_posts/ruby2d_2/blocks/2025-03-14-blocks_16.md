## {{ page.section_title }}

### ライフ変数とテキストを作る

main.rb（`score_text` の下に追加）

```ruby
life = 3
life_text = Text.new("Life: 3", x: 10, y: 35, size: 20)
```

### 落下時にライフを減らす

`Ball#fall_down` がライフを減らせるように、`life` を渡します。

main.rb（`update do` を更新）

```ruby
update do
  ball.move(bar, life)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
  life_text.text  = "Life: #{life}"
end
```

### Ball#move と fall_down を更新する

app/ball.rb（`move` の引数と `fall_down` 呼び出しを更新）

```ruby
def move(bar, life)
  if self.is_move
    self.x += self.x_flag ? self.speed : -self.speed
    self.y += self.y_flag ? self.speed : -self.speed
    reflect_wall
    refrect(bar)
    fall_down(life)
  else
    follow(bar)
  end
end
```

app/ball.rb（`fall_down` を更新）

```ruby
def fall_down(life)
  if self.y > Window.height
    life -= 1
    self.is_move = false
    self.x_flag  = true
    self.y_flag  = false
  end
end
```

ただし、このままでは `life -= 1` が `main.rb` 側の変数を変えません。Ruby では数値は参照ではなく値渡しになるためです。

### life を配列で渡す

値渡しの問題を回避するため、`life` を1要素の配列にします。

main.rb（変数の変更）

```ruby
life = [3]
life_text = Text.new("Life: #{life[0]}", x: 10, y: 35, size: 20)
```

main.rb（`update do` の表示を更新）

```ruby
life_text.text = "Life: #{life[0]}"
```

app/ball.rb（`fall_down` を更新）

```ruby
def fall_down(life)
  if self.y > Window.height
    life[0] -= 1
    self.is_move = false
    self.x_flag  = true
    self.y_flag  = false
  end
end
```

`life[0]` を変えると `main.rb` 側の配列の中身も変わるため、ライフが正しく減るようになります。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ボールが落ちるたびにライフが減り、画面に表示される。ライフが0になってもまだゲームオーバーにはならない（次のセクションで追加）。

### ここまでのコード

app/ball.rb（変更部分のみ）

```ruby
def move(bar, life)
  if self.is_move
    self.x += self.x_flag ? self.speed : -self.speed
    self.y += self.y_flag ? self.speed : -self.speed
    reflect_wall
    refrect(bar)
    fall_down(life)
  else
    follow(bar)
  end
end

# private の中

def fall_down(life)
  if self.y > Window.height
    life[0] -= 1
    self.is_move = false
    self.x_flag  = true
    self.y_flag  = false
  end
end
```

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
require_relative "app/block"

set width: 800, height: 600

bar    = Bar.new
ball   = Ball.new
blocks = Block.set_blocks
score  = 0
life   = [3]
score_text = Text.new("Score: 0", x: 10, y: 10, size: 20)
life_text  = Text.new("Life: 3",  x: 10, y: 35, size: 20)

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar, life)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
  life_text.text  = "Life: #{life[0]}"
end

show
```
