### GameOverクラスを作る

`Bar`・`Ball`・`Block` と同じパターンで、ゲームオーバー画面をクラスにまとめます。

app/game_over.rb

```ruby
class GameOver
  ATTRIBUTES = {
    title: { text: "GAME OVER", x: 250, y: 220, size: 50, color: "red" },
    guide: { text: "Press R to restart", x: 270, y: 300, size: 22 }
  }

  def initialize
    @texts = ATTRIBUTES.map do |_, attrs|
      Text.new(attrs[:text], x: attrs[:x], y: attrs[:y], size: attrs[:size])
    end
    @texts[0].color = ATTRIBUTES[:title][:color]
  end

  def show
    @texts.each { |t| t.color = t.color }
  end

  def remove
    @texts.each(&:remove)
  end
end
```

- `ATTRIBUTES` — 定数にテキストの設定をまとめています
- `initialize` — `Text.new` を複数まとめて作ります
- `show` / `remove` — 他のクラスと同じインターフェースになるよう名前を合わせます

### main.rb に組み込む

main.rb（`require_relative` に追加）

```ruby
require_relative "app/game_over"
```

main.rb（変数を追加）

```ruby
game_over = nil
```

main.rb（`update do` を更新）

```ruby
update do
  if game_over
    on :key_down do |event|
      if event.key == "r"
        game_over.remove
        game_over = nil
        ball   = Ball.new
        blocks = Block.set_blocks
        score  = 0
        life   = [3]
        score_text.text = "Score: 0"
        life_text.text  = "Life: 3"
      end
    end
    next
  end

  ball.move(bar, life)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
  life_text.text  = "Life: #{life[0]}"

  if life[0] <= 0 && !game_over
    game_over = GameOver.new
  end
end
```

- `game_over` が存在する間はボールを動かさず、`R` キーでリセットします
- `next` でそれ以降の処理をスキップします

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ライフが0になると「GAME OVER」が表示される。R キーを押すとリセットして再スタートできる。

#### *ここで試したいこと

- `GAME OVER` の文字サイズや色を変えてみよう。
- ガイドメッセージを「Press C to continue」に変えてキーも `c` にしてみよう。

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
require_relative "app/block"
require_relative "app/game_over"

set width: 800, height: 600

bar       = Bar.new
ball      = Ball.new
blocks    = Block.set_blocks
score     = 0
life      = [3]
game_over = nil
score_text = Text.new("Score: 0", x: 10, y: 10, size: 20)
life_text  = Text.new("Life: 3",  x: 10, y: 35, size: 20)

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move && !game_over
    ball.is_move = true
  end
end

update do
  if game_over
    next
  end

  ball.move(bar, life)
  score += Block.broken_by(ball, blocks)
  score_text.text = "Score: #{score}"
  life_text.text  = "Life: #{life[0]}"

  if life[0] <= 0
    game_over = GameOver.new
  end
end

on :key_down do |event|
  if game_over && event.key == "r"
    game_over.remove
    game_over = nil
    ball      = Ball.new
    blocks    = Block.set_blocks
    score     = 0
    life      = [3]
    score_text.text = "Score: 0"
    life_text.text  = "Life: 3"
  end
end

show
```
