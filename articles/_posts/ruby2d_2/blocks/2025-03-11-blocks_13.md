### broken_by クラスメソッドを追加する

`Block.broken_by(ball, blocks)` を呼ぶと、全ブロックへの当たり判定をまとめて処理します。

app/block.rb（クラスに追加）

```ruby
def self.broken_by(ball, blocks)
  blocks.each do |block|
    block.refrect(ball, blocks)
  end
end
```

### refrect と上・下の判定を追加する

app/block.rb（クラスに追加）

```ruby
def refrect(ball, blocks)
  top_refrect(ball, blocks) ||
  bottom_refrect(ball, blocks)
end

private

def top_refrect(ball, blocks)
  contain = ball.contains?(ball.x, self.y - ball.radius)
  range   = ball.x >= self.x && ball.x <= self.x + self.width
  if contain && range
    ball.y_flag = false
    self.remove
    blocks.delete(self)
  end
end

def bottom_refrect(ball, blocks)
  contain = ball.contains?(ball.x, self.y + self.height + ball.radius)
  range   = ball.x >= self.x && ball.x <= self.x + self.width
  if contain && range
    ball.y_flag = true
    self.remove
    blocks.delete(self)
  end
end
```

- `ball.contains?(ball.x, self.y - ball.radius)` — ブロック上面がボールの範囲内かを確認します
- `range` — ボールのx座標がブロックの横幅の中にあるかを確認します
- `self.remove` で画面から消し、`blocks.delete(self)` で配列からも削除します

### main.rb に追加する

main.rb（`update do` を更新）

```ruby
update do
  ball.move(bar)
  Block.broken_by(ball, blocks)
end
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ボールがブロックの上・下に当たるとブロックが消え、ボールが跳ね返る。左・右に当たったときはまだ貫通する。

#### *ここで試したいこと

- `blocks.delete(self)` を消すとどうなるか試してみよう（画面からは消えるが、配列に残り続ける）。
- ボールがブロックの横に当たったときに貫通することを確認しよう。

### ここまでのコード

app/block.rb

```ruby
class Block < Rectangle
  BLOCK_COLORS = %w(
    red
    orange
    yellow
    green
    blue
    fuchsia
    purple
  )

  def initialize
    super(width: 80, height: 25)
    self.x = self.width / 2
    self.y = self.height * 2
  end

  def self.set_blocks
    BLOCK_COLORS.map.with_index(0) do |color, r|
      9.times.map do |c|
        block = self.new
        block.color = color
        block.x += block.width * c
        block.y += block.height * r
        block.width  -= 1
        block.height -= 1
        block
      end
    end.flatten
  end

  def self.broken_by(ball, blocks)
    blocks.each do |block|
      block.refrect(ball, blocks)
    end
  end

  def refrect(ball, blocks)
    top_refrect(ball, blocks) ||
    bottom_refrect(ball, blocks)
  end

  private

  def top_refrect(ball, blocks)
    contain = ball.contains?(ball.x, self.y - ball.radius)
    range   = ball.x >= self.x && ball.x <= self.x + self.width
    if contain && range
      ball.y_flag = false
      self.remove
      blocks.delete(self)
    end
  end

  def bottom_refrect(ball, blocks)
    contain = ball.contains?(ball.x, self.y + self.height + ball.radius)
    range   = ball.x >= self.x && ball.x <= self.x + self.width
    if contain && range
      ball.y_flag = true
      self.remove
      blocks.delete(self)
    end
  end
end
```

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
require_relative "app/block"

set width: 800, height: 600

bar    = Bar.new
ball   = Ball.new
blocks = Block.set_blocks

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
  Block.broken_by(ball, blocks)
end

show
```
