## {{ page.section_title }}

### ディレクトリを作る

`app` ディレクトリを作り、その中にクラスファイルを置きます。

```bash
ruby2d/blocks $ mkdir app
ruby2d/blocks $ touch app/bar.rb
ruby2d/blocks $ touch app/ball.rb
```

### Bar クラスを移動する

`main.rb` から `Bar` クラスをまるごと切り取り、`app/bar.rb` に貼り付けます。

app/bar.rb

```ruby
class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end

  def move(event)
    if event.key == "left"
      self.x -= self.speed
    end
    if event.key == "right"
      self.x += self.speed
    end
    limit
  end

  private

  def limit
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end
```

### Ball クラスを移動する

`main.rb` から `Ball` クラスをまるごと切り取り、`app/ball.rb` に貼り付けます。

app/ball.rb

```ruby
class Ball < Circle
  attr_accessor :x_flag, :y_flag, :speed, :is_move

  def initialize
    super(radius: 10)
    self.speed   = 5
    self.x_flag  = true
    self.y_flag  = false
    self.is_move = false
    self.x = Window.width / 2
    self.y = Window.height / 2
  end

  def move(bar)
    if self.is_move
      self.x += self.x_flag ? self.speed : -self.speed
      self.y += self.y_flag ? self.speed : -self.speed
      reflect_wall
      fall_down
    else
      follow(bar)
    end
  end

  private

  def reflect_wall
    self.y_flag = true  if self.contains?(self.x, 0)
    self.x_flag = true  if self.contains?(0, self.y)
    self.x_flag = false if self.contains?(Window.width, self.y)
  end

  def follow(bar)
    self.x = bar.x + bar.width / 2
    self.y = bar.y - self.radius
  end

  def fall_down
    if self.y > Window.height
      self.is_move = false
      self.x_flag  = true
      self.y_flag  = false
    end
  end
end
```

### main.rb に require を追加する

main.rb の先頭に読み込みを追加します。

main.rb（先頭を更新）

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

動きは変わらない。`main.rb` がすっきりし、クラスはそれぞれのファイルで管理できるようになった。

#### *ここで試したいこと

- `require_relative` を1つ消して実行するとどんなエラーが出るか確認しよう。
- `app/bar.rb` と `app/ball.rb` に直接 `p "bar loaded"` などを書いて読み込まれているか確認しよう。

main.rb

```ruby
require "ruby2d"
require_relative "app/bar"
require_relative "app/ball"

bar  = Bar.new
ball = Ball.new

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
end

show
```
