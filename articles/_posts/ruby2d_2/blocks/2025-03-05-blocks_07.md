## {{ page.section_title }}

### move メソッドを作る

キー入力の処理を `Bar` クラスの `move` メソッドにまとめます。

main.rb（`Bar` クラスに追加）

```ruby
def move(event)
  if event.key == "left"
    self.x -= self.speed
  end
  if event.key == "right"
    self.x += self.speed
  end
  limit
end
```

### limit を private メソッドにする

`limit` はクラスの外から呼ばれない内部処理です。`private` の下に書くとクラスの外から呼べなくなります。

main.rb（`Bar` クラスに追加）

```ruby
private

def limit
  self.x = 0 if self.x < 0
  self.x = Window.width - self.width if self.x > Window.width - self.width
end
```

### on :key を更新する

main.rb

```ruby
on :key do |event|
  bar.move(event)
end
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

動きは変わらない。バーの移動とはみ出し制限が `Bar` クラスにまとまった。

#### *ここで試したいこと

- `bar.limit` と書いてみよう。`private method called` というエラーが出ることを確認しよう。
- `move` の中で `p event.key` を入れてキー名を確認してみよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end

  def move(event)
    if event.key == "left"
      self.x -= self.speed
    end
    if event.key == "right"
      self.x += self.speed
    end
    limit
  end

  private

  def limit
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end

bar = Bar.new

ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2

x_flag = true
y_flag = false
speed = 5
is_move = false

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !is_move
    is_move = true
  end
end

update do
  if is_move
    ball.x += x_flag ? speed : -speed
    ball.y += y_flag ? speed : -speed

    y_flag = true  if ball.contains?(ball.x, 0)
    x_flag = true  if ball.contains?(0, ball.y)
    x_flag = false if ball.contains?(Window.width, ball.y)

    if ball.y > Window.height
      is_move = false
      x_flag = true
      y_flag = false
    end
  else
    ball.x = bar.x + bar.width / 2
    ball.y = bar.y - ball.radius
  end
end

show
```
