## {{ page.section_title }}

### move メソッドを作る

`update do` の中のボール処理を `Ball` クラスの `move` メソッドにまとめます。

main.rb（`Ball` クラスに追加）

```ruby
def move(bar)
  if self.is_move
    self.x += self.x_flag ? self.speed : -self.speed
    self.y += self.y_flag ? self.speed : -self.speed
    reflect_wall
    fall_down
  else
    follow(bar)
  end
end
```

### reflect_wall と follow と fall_down を private にする

main.rb（`Ball` クラスに追加）

```ruby
private

def reflect_wall
  self.y_flag = true  if self.contains?(self.x, 0)
  self.x_flag = true  if self.contains?(0, self.y)
  self.x_flag = false if self.contains?(Window.width, self.y)
end

def follow(bar)
  self.x = bar.x + bar.width / 2
  self.y = bar.y - self.radius
end

def fall_down
  if self.y > Window.height
    self.is_move = false
    self.x_flag  = true
    self.y_flag  = false
  end
end
```

### update do をすっきりさせる

main.rb（`update do` を更新）

```ruby
update do
  ball.move(bar)
end
```

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

動きは変わらない。`update do` が1行になりすっきりした。

#### *ここで試したいこと

- `update do` の中身が1行になっていることを確認しよう。
- `Bar` と `Ball` のコードの構造を比べてみよう。どちらも同じパターンで作られている。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

class Bar < Rectangle
  attr_accessor :speed

  def initialize
    super
    self.speed = 5
    self.width = 100
    self.height = 15
    self.x = (Window.width - self.width) / 2
    self.y = Window.height - self.height * 3
  end

  def move(event)
    if event.key == "left"
      self.x -= self.speed
    end
    if event.key == "right"
      self.x += self.speed
    end
    limit
  end

  private

  def limit
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end

class Ball < Circle
  attr_accessor :x_flag, :y_flag, :speed, :is_move

  def initialize
    super(radius: 10)
    self.speed   = 5
    self.x_flag  = true
    self.y_flag  = false
    self.is_move = false
    self.x = Window.width / 2
    self.y = Window.height / 2
  end

  def move(bar)
    if self.is_move
      self.x += self.x_flag ? self.speed : -self.speed
      self.y += self.y_flag ? self.speed : -self.speed
      reflect_wall
      fall_down
    else
      follow(bar)
    end
  end

  private

  def reflect_wall
    self.y_flag = true  if self.contains?(self.x, 0)
    self.x_flag = true  if self.contains?(0, self.y)
    self.x_flag = false if self.contains?(Window.width, self.y)
  end

  def follow(bar)
    self.x = bar.x + bar.width / 2
    self.y = bar.y - self.radius
  end

  def fall_down
    if self.y > Window.height
      self.is_move = false
      self.x_flag  = true
      self.y_flag  = false
    end
  end
end

bar  = Bar.new
ball = Ball.new

on :key do |event|
  bar.move(event)
end

on :key_down do |event|
  if event.key == "space" && !ball.is_move
    ball.is_move = true
  end
end

update do
  ball.move(bar)
end

show
```
