## {{ page.section_title }}

### 完成したゲームを通しで確認しよう

- バーを動かしてボールを発射できるか
- ブロックに当たると消えてスコアが増えるか
- ボールが落ちるとライフが減るか
- ライフが0になると GAME OVER が表示されるか
- R キーでリセットできるか

### 改造アイデア

#### 1. ボールの速さをランダムにする

発射のたびにランダムな速さにすると難易度が変わります。

main.rb（`on :key_down` を更新）

```ruby
on :key_down do |event|
  if event.key == "space" && !ball.is_move && !game_over
    ball.speed   = rand(3..8)
    ball.is_move = true
  end
end
```

#### 2. 行ごとに得点を変える

上の行ほど得点が高くなるようにしてみよう。

app/block.rb に `attr_accessor :point` を追加し、`set_blocks` の中で行番号から得点を設定します。

```ruby
attr_accessor :point

# set_blocks の中
block.point = (BLOCK_COLORS.size - r) * 10
```

`broken_by` の `point +=` を `point += block.point` に変えます。

#### 3. ブロックを全部壊したらクリアにする

`update do` の中で `blocks.size == 0` を確認してメッセージを出しましょう。

```ruby
if blocks.size == 0 && !game_over
  # クリアメッセージを表示する処理
end
```

#### 4. バーのはじく位置で角度を変える

ボールがバーのどこに当たったかで `x_flag` を変えると、より本格的なブロック崩しになります。

### お疲れさまでした！

このカリキュラムでは次のことを学びました：

- `Rectangle`・`Circle` でゲームオブジェクトを作る
- `x_flag`・`y_flag` で方向を管理する
- `class`・`initialize`・`attr_accessor` でクラスを定義する
- `private` で内部処理を隠す
- `require_relative` でファイルを分ける
- `self.メソッド名` でクラスメソッドを定義する
- 定数（`BLOCK_COLORS`・`ATTRIBUTES`）でデータをまとめる
