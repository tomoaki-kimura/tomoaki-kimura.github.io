## {{ page.section_title }}

### ボールを表示する

`Circle` クラスでボールを作ります。

main.rb（バーの下に追加）

```ruby
ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2
```

### フラグで移動方向を管理する

`x_flag`・`y_flag` でボールの方向を管理します。`true` のとき正方向（右・下）、`false` のとき負方向（左・上）に動きます。

main.rb（変数を追加）

```ruby
x_flag = true
y_flag = false
speed = 5
```

### update do でボールを動かす

main.rb

```ruby
update do
  ball.x += x_flag ? speed : -speed
  ball.y += y_flag ? speed : -speed

  y_flag = true  if ball.contains?(ball.x, 0)
  x_flag = true  if ball.contains?(0, ball.y)
  x_flag = false if ball.contains?(Window.width, ball.y)
end
```

天井・左壁・右壁でフラグを反転させます。下（落下）はこの後実装します。

### ファイルの実行

```bash
ruby2d/blocks $ ruby main.rb
```

### 結果

ボールが画面を跳ね回る。まだバーとは関係なく動き続ける。

#### *ここで試したいこと

- `speed` を変えてボールの速さを変えてみよう。
- `y_flag` の初期値を `true` にしたらどの方向に動き出すか確認しよう。

### ここまでのコード

main.rb

```ruby
require "ruby2d"

bar = Rectangle.new(width: 100, height: 15)
bar.x = (Window.width - bar.width) / 2
bar.y = Window.height - bar.height * 3

ball = Circle.new(radius: 10)
ball.x = Window.width / 2
ball.y = Window.height / 2

x_flag = true
y_flag = false
speed = 5

on :key do |event|
  if event.key == "left"
    bar.x -= 5
    bar.x = 0 if bar.x < 0
  end
  if event.key == "right"
    bar.x += 5
    bar.x = Window.width - bar.width if bar.x > Window.width - bar.width
  end
end

update do
  ball.x += x_flag ? speed : -speed
  ball.y += y_flag ? speed : -speed

  y_flag = true  if ball.contains?(ball.x, 0)
  x_flag = true  if ball.contains?(0, ball.y)
  x_flag = false if ball.contains?(Window.width, ball.y)
end

show
```
