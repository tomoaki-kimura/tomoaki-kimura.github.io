### このチャプターで作るもの

このチャプターでは、**落ちものブロックパズルゲーム**を Ruby2D で作ります。

ブロックが上から落ちてきて、横一列が埋まると消える——おなじみのあのゲームです。  
ゲーム自体はシンプルですが、きちんと動かすには**ゲームの状態管理・クラス設計・物理ロジック**など、プログラミングのエッセンスが詰まっています。

完成したゲームの仕様は次のとおりです。

| 操作 | キー |
|---|---|
| 左右移動 | `A` / `D` |
| ソフトドロップ（加速） | `S` |
| 左回転 / 右回転 | `J` / `K` |
| スタート | `Space` |
| リスタート | `R` |

| 機能 | 内容 |
|---|---|
| ブロックの種類 | 7種類（I・J・L・O・S・T・Z型） |
| スコア | 消したライン数に応じて加算（1〜4ライン） |
| レベル | 10ライン消すごとにレベルアップ、落下速度が上がる |
| NEXT表示 | 次のブロックをパネルに表示 |
| ライン消去演出 | 消える前に点滅 |
| ゲームオーバー | ブロックが上端に達したら終了 |

### なぜこのゲームを作るのか

このゲームはただ作って遊ぶだけではなく、**リリースを見据えた設計**を体験することが目的です。

Ruby2D では `ruby2d build --web` コマンドを使うことで、作ったゲームを **WebAssembly（WASM）**にコンパイルしてブラウザで動かすことができます。  
完成したゲームは GitHub Pages などに置けば、友達や家族に URL を送るだけで遊んでもらえます。

```
「作った！動いた！」で終わるのではなく、
「人に届けられる形にする」ところまでがゴールです。
```

### Ruby2D 1.0.0 と WASM 対応

2026年、Ruby2D のバージョン 1.0.0 がリリースされました。  
この版から **WASM ビルドが正式にサポート**され、Ruby で書いたゲームをそのままブラウザで動かせるようになりました。

以前は実験的な機能でしたが、1.0.0 では SDL3 ベースに刷新され、安定して動作します。  
このチャプターでは **Ruby2D 1.0.0** を前提に進めます。

> **Note:** Ruby2D 1.0.0 では一部の API が変更されています（例：`Text` の内容更新は `.text=` ではなく `.content=`）。  
> 古いバージョンのコードをそのまま使うと動かないことがあるので注意してください。
