### レベルと弾の本数

`fighter.level` が上がると弾の本数が増えます。

| level | 弾の本数 | 計算式 |
|-------|---------|--------|
| 1 | 1本 | `1 * 2 - 1 = 1` |
| 2 | 3本 | `2 * 2 - 1 = 3` |
| 3 | 5本 | `3 * 2 - 1 = 5` |

### ANGLE_OFFSET 定数を追加する

各弾の角度のずれを定数で定義します。

app/models/bullet.rb

```ruby
class Bullet < Circle
  ANGLE_OFFSET = [0, -15, 15, -30, 30]
  attr_accessor :speed, :angle

  def initialize
    super(radius: 3)
    self.speed = 15
    self.angle = 0
  end

  def self.set(bullets, fighter)
    bullet_size = fighter.level * 2 - 1
    bullet_size.times do |i|
      bullet = self.new
      bullet.x = fighter.x + (fighter.width / 2)
      bullet.y = fighter.y
      bullet.angle = ANGLE_OFFSET[i]
      bullets << bullet
    end
  end

  def self.move(bullets)
    bullets.each do |bullet|
      r = (bullet.angle + 90) * PI / 180
      bullet.x += cos(r) * bullet.speed
      bullet.y -= sin(r) * bullet.speed
    end
  end
end
```

`ANGLE_OFFSET` は大文字で始まる定数です。1本目は角度0（真上）、2本目は-15度（左）、3本目は+15度（右）…と広がっていきます。

### 動作確認のため level を変えてみる

`fighter.level` を直接変えて弾の本数が変わるか確認してみましょう。`app/main.rb` に以下を追加します（確認後は削除）。

```ruby
# 確認用：スペースキー押下後に一時的に level を変更
fighter.level = 2  # 3本になるか確認
fighter.level = 3  # 5本になるか確認
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

`level` が2なら扇状に3本、3なら5本の弾が発射される。

#### *ここで試したいこと

- `ANGLE_OFFSET` の角度を変えて弾の広がり方を変えてみよう。
- `level` を手動で変えて弾の本数が正しく変わるか確認しよう。
