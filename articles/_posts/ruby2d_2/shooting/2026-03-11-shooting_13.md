### アニメーション付きSpriteを作る

`Sprite` の `animations:` オプションで、画像の複数コマをアニメーションとして登録できます。

`enemy_1.png` は2×2の4コマが入っており、`play` メソッドでコマが順番に切り替わります。

### Enemy1クラスを作る

`app/models/enemy_1.rb` を新規作成しましょう。

app/models/enemy_1.rb

```ruby
class Enemy1 < Sprite
  SCORE = 100
  attr_accessor :speed

  def initialize
    super("./app/images/enemy_1.png",
      width: 30,
      height: 30,
      animations: {
        roll: [
          { width: 15, height: 15, x: 0,  y: 0  },
          { width: 15, height: 15, x: 15, y: 0  },
          { width: 15, height: 15, x: 0,  y: 15 },
          { width: 15, height: 15, x: 15, y: 15 }
        ]
      }
    )
    self.x = rand(0..(Window.width - self.width))
    self.y = 0 - self.height
    self.play(animation: :roll, loop: true)
    self.speed = 3
  end
end
```

`SCORE = 100` は定数です。後のセクションでスコア加算に使います。

### app/main.rb に enemies 配列を追加して敵を生成する

app/main.rb（enemies を追加）

```ruby
enemies = []
```

update do の `:start` ブロックに追加

```ruby
enemies << Enemy1.new if tick % 20 == 0 && rand(0..2) == 0
```

```bash
shooting $ bundle exec rake
```

### 結果

画面上部からランダムな位置にアニメーションする敵がスポーンする。まだ動かない。

#### *ここで試したいこと

- `tick % 20` の数字を変えて出現頻度を変えてみよう。
- `rand(0..2)` の範囲を変えてスポーン確率を変えてみよう（数字が大きいほど出にくくなる）。
