### プロジェクトの構成

ヘビゲームは `main.rb` 1ファイルで作りましたが、シューティングゲームはファイル数が多くなるため、以下のような構成で作ります。

```
shooting/
├── Gemfile
├── Rakefile
├── config.rb
└── app/
    ├── main.rb
    ├── images/
    ├── messages/
    └── models/
```

`images/` には画像ファイル、`messages/` にはゲームの画面クラス、`models/` にはキャラクターのクラスを入れます。

### Gemfile と Rakefile の作成

`shooting` ディレクトリに以下の2ファイルを作りましょう。

Gemfile

```
source "https://rubygems.org"

gem "ruby2d"
gem "rake"
gem "byebug"
```

Rakefile

```ruby
task default: %w[game]

task :game do
  ruby "app/main.rb"
end
```

`Rakefile` は `rake` コマンドで実行するためのファイルです。`bundle exec rake` と打つと、`ruby app/main.rb` を自動で実行してくれます。

次に `bundle install` でgemをインストールします。

```bash
shooting $ bundle install
```

### config.rb と app/main.rb の作成

config.rb

```ruby
require "ruby2d"

set width: 600, height: 800
```

app/main.rb

```ruby
require "./config"

show
```

`app/main.rb` の `require "./config"` で、`shooting/config.rb` を読み込みます。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

600×800 のウィンドウが立ち上がればOK。
