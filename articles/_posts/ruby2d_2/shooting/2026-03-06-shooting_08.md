### 三角関数で移動方向を計算する

弾の移動に `cos` と `sin` を使います。角度をラジアンに変換する式は以下です。

```
ラジアン = 角度 × π ÷ 180
```

`angle` が `0`（真上方向）のとき：

```ruby
r = (0 + 90) * PI / 180  # 90度をラジアンに変換
x の変化 = cos(r) * speed # → 0（横には動かない）
y の変化 = sin(r) * speed # → 1（上方向）
```

### config.rb に include Math を追加する

`cos`・`sin`・`PI` を使うために `include Math` を追加します。

config.rb

```ruby
require "ruby2d"
include Math

set width: 600, height: 800

require "./app/messages/game_title"
require "./app/status"
require "./app/models/fighter"
require "./app/models/bullet"
```

### Bullet に move メソッドを追加する

app/models/bullet.rb

```ruby
class Bullet < Circle
  attr_accessor :speed, :angle

  def initialize
    super(radius: 3)
    self.speed = 15
    self.angle = 0
  end

  def self.set(bullets, fighter)
    bullet = self.new
    bullet.x = fighter.x + (fighter.width / 2)
    bullet.y = fighter.y
    bullets << bullet
  end

  def self.move(bullets)
    bullets.each do |bullet|
      r = (bullet.angle + 90) * PI / 180
      bullet.x += cos(r) * bullet.speed
      bullet.y -= sin(r) * bullet.speed
    end
  end
end
```

### app/main.rb で Bullet.move を呼び出す

app/main.rb（update do の中を変更）

```ruby
update do
  case @status.game_status
  when :title
  when :start
    fighter.opening_action
    Bullet.move(bullets)
  end
end
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

Jキーで発射した弾が画面上方向に飛んでいく。画面外に出ても消えないので弾が増え続ける。

#### *ここで試したいこと

- `speed` を変えて弾の速さを変えてみよう。
- `angle` を `45` に変えたらどの方向に飛ぶか試してみよう。
