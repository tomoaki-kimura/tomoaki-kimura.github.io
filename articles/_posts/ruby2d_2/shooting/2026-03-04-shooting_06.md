## {{ page.section_title }}

### 自機の傾き

`fighter.png` には「正面・右向き」の2コマが横に並んでいます。`clip_x` で切り出す位置を変えると画像が切り替わり、`flip_sprite(:horizontal)` で左右反転できます。

### Fighter に傾きとオープニングを追加する

app/models/fighter.rb

```ruby
class Fighter < Sprite
  attr_accessor :speed, :tick, :status, :pow, :level, :life, :life_gauge

  def initialize
    super("app/images/fighter.png")
    self.width = 30
    self.height = 30
    self.clip_width = 15
    self.clip_height = 15
    self.speed = 3.0
    self.remove
    self.tick = 0
    self.status = nil
    self.pow = 0
    self.level = 1
    self.life = 3
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end

  def move(key)
    right_move if key == "d"
    left_move  if key == "a"
    self.y -= self.speed if key == "w"
    self.y += self.speed if key == "s"
    window_limit
  end

  def nutral(key)
    center_image if key == "d" || key == "a"
  end

  def opening_action
    case self.status
    when :clear
      self.x = (Window.width - self.width) / 2
      self.y = Window.height - self.height
      self.status = :starting
    when :starting
      self.y -= 1
      self.color = "random"
      if self.y < Window.height / 4 * 3
        self.status = :ready
        self.color = "white"
      end
    end
  end

  private

  def right_move
    self.x += self.speed
    self.clip_x = 15
    self.flip_sprite(nil)
  end

  def left_move
    self.x -= self.speed
    self.clip_x = 15
    self.flip_sprite(:horizontal)
  end

  def center_image
    self.clip_x = 0
    self.flip_sprite(nil)
  end

  def window_limit
    self.y = 0 if self.y < 0
    self.y = Window.height - self.height if self.y > Window.height - self.height
    self.x = 0 if self.x < 0
    self.x = Window.width - self.width if self.x > Window.width - self.width
  end
end
```

`opening_action` は `:clear` → `:starting` → `:ready` の順に状態が変わります。

### app/main.rb を更新する

app/main.rb

```ruby
require "./config"

@status = Status.new
fighter = Fighter.new
game_title = GameTitle.new

update do
  case @status.game_status
  when :title
  when :start
    fighter.opening_action
  end
end

on :key do |event|
  key = event.key
  case fighter.status
  when :ready
    fighter.move(key)
  end
end

on :key_down do |event|
  key = event.key
  case key
  when "space"
    if @status.game_status == :title
      game_title.remove
      fighter.status = :clear
      @status.to_start
      fighter.add
    end
  end
end

on :key_up do |event|
  fighter.nutral(event.key)
end

show
```

`fighter.status = :clear` にしてから `fighter.add` するとオープニングが始まります。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

スペースキーを押すと画面下から自機がカラフルに光りながら上昇し、一定の位置で止まって操作できるようになる。

#### *ここで試したいこと

- `Window.height / 4 * 3` を変えてオープニングの終点を変えてみよう。
- Dキーを押したまま放すと自機が正面に戻ることを確認しよう。
