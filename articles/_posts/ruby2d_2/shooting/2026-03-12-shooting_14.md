## {{ page.section_title }}

### Enemy1 に move メソッドを追加する

app/models/enemy_1.rb

```ruby
class Enemy1 < Sprite
  SCORE = 100
  attr_accessor :speed

  def initialize
    # 前回と同じ
  end

  def move(enemies)
    self.y += self.speed
    if self.y > Window.height
      self.remove
      enemies.delete(self)
    end
  end
end
```

`self.remove` で画面から消し、`enemies.delete(self)` で配列からも取り除きます。両方やらないとメモリが増え続けてしまいます。

### app/main.rb で敵を動かす

update do の `:start` ブロックに追加します。

app/main.rb

```ruby
when :start
  fighter.opening_action
  Bullet.move(bullets)
  items.each { |item| item.move }
  items.each { |item| item.touch(fighter, items) }
  enemies << Enemy1.new if tick % 20 == 0 && rand(0..2) == 0
  enemies.each { |enemy| enemy.move(enemies) }
```

敵が上から下に移動し、画面の下端を超えると消える。

### ここまでのコード

app/models/enemy_1.rb

```ruby
class Enemy1 < Sprite
  SCORE = 100
  attr_accessor :speed

  def initialize
    super("./app/images/enemy_1.png",
      width: 30,
      height: 30,
      animations: {
        roll: [
          { width: 15, height: 15, x: 0,  y: 0  },
          { width: 15, height: 15, x: 15, y: 0  },
          { width: 15, height: 15, x: 0,  y: 15 },
          { width: 15, height: 15, x: 15, y: 15 }
        ]
      }
    )
    self.x = rand(0..(Window.width - self.width))
    self.y = 0 - self.height
    self.play(animation: :roll, loop: true)
    self.speed = 3
  end

  def move(enemies)
    self.y += self.speed
    if self.y > Window.height
      self.remove
      enemies.delete(self)
    end
  end
end
```
