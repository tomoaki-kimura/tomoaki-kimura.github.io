### Status にハイスコアを追加する

app/status.rb

```ruby
class Status
  attr_reader :game_status, :score, :high_score

  def initialize
    @score = 0
    @high_score = 0
    @score_display = Text.new("Score: 0", x: 20, y: 40, size: 20)
    @high_score_display = Text.new("Best: 0", x: 20, y: 65, size: 20)
    to_title
  end

  def to_title
    @game_status = :title
  end

  def to_start
    @game_status = :start
  end

  def to_game_over
    if @score > @high_score
      @high_score = @score
      @high_score_display.remove
      @high_score_display = Text.new("Best: #{@high_score}", x: 20, y: 65, size: 20)
    end
    @game_status = :game_over
  end

  def add_score(points)
    @score += points
    @score_display.remove
    @score_display = Text.new("Score: #{@score}", x: 20, y: 40, size: 20)
  end

  def reset_score
    @score = 0
    @score_display.remove
    @score_display = Text.new("Score: 0", x: 20, y: 40, size: 20)
  end
end
```

`to_game_over` の中でスコアとハイスコアを比較し、上回っていたら更新します。ハイスコアはリスタートしても消えません。

### GameOver にスコアを表示する

ゲームオーバー画面に今回のスコアを表示するよう変更します。

app/messages/game_over.rb

```ruby
class GameOver
  attr_accessor :title, :score_text, :message

  def initialize
    self.title = Text.new("GAME OVER", size: 60)
    self.title.x = (Window.width - self.title.width) / 2
    self.title.y = 260
    self.score_text = Text.new("", size: 30)
    self.message = Text.new("press key 'R' to restart", size: 30)
    self.message.x = (Window.width - self.message.width) / 2
    self.message.y = 460
  end

  def add(score)
    self.title.add
    self.score_text.remove
    self.score_text = Text.new("Score: #{score}", size: 30)
    self.score_text.x = (Window.width - self.score_text.width) / 2
    self.score_text.y = 360
    self.score_text.add
    self.message.add
  end

  def remove
    self.title.remove
    self.score_text.remove
    self.message.remove
  end
end
```

### app/main.rb の game_over.add を更新する

```ruby
if fighter.life <= 0
  fighter.remove
  @status.to_game_over
  game_over.add(@status.score)
end
```

### 結果

ゲームオーバー時に今回のスコアが表示される。リスタートしても画面左上の「Best:」は更新されたスコアのまま残る。

#### *ここで試したいこと

- ハイスコアがリスタートしても消えないことを確認しよう。
- スコアがハイスコアを超えたとき「Best:」表示が更新されることを確認しよう。
