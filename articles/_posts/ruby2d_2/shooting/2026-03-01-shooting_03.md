## {{ page.section_title }}

### Statusクラスを作る

ゲームの状態（タイトル画面なのか、プレイ中なのか）を管理するクラスを作ります。

`app/status.rb` を新規作成しましょう。

app/status.rb

```ruby
class Status
  attr_reader :game_status

  def initialize
    to_title
  end

  def to_title
    @game_status = :title
  end

  def to_start
    @game_status = :start
  end
end
```

`attr_reader` は読み取り専用の `attr_accessor` です。`game_status` は外から直接書き換えられず、`to_title` や `to_start` メソッドを通してだけ変更できます。

### config.rb に require を追加する

config.rb

```ruby
require "ruby2d"

set width: 600, height: 800

require "./app/messages/game_title"
require "./app/status"
```

### app/main.rb にゲーム開始の処理を書く

app/main.rb

```ruby
require "./config"

@status = Status.new
game_title = GameTitle.new

update do
  case @status.game_status
  when :title
  when :start
  end
end

on :key_down do |event|
  key = event.key
  case key
  when "space"
    if @status.game_status == :title
      game_title.remove
      @status.to_start
    end
  end
end

show
```

`@status` の `@` は、`update do` ブロックや `on :key_down do` ブロックの中からも使えるインスタンス変数です。

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

スペースキーを押すとタイトルが消える。まだゲーム内容はないので画面は真っ暗になる。

#### *ここで試したいこと

- スペース以外のキー（例："return"）でもスタートできるか試してみよう。
- `p @status.game_status` を `update do` の中に入れて、状態の変化をターミナルで確認してみよう。
