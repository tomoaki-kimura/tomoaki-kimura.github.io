### 無敵時間の仕組み

被弾したら `invincible` フラグを `true` にして、`check_point` でカウントします。カウント中は透明度を交互に変えて点滅させ、一定フレーム後にフラグを `false` に戻します。

### Fighter に無敵時間を追加する

`attr_accessor` に `invincible` と `check_point` を追加し、`bloken_by` と `update_invincible` を更新・追加します。

app/models/fighter.rb

```ruby
class Fighter < Sprite
  attr_accessor :speed, :tick, :check_point, :status,
                :pow, :level, :life, :life_gauge, :invincible

  INVINCIBLE_DURATION = 120

  def initialize
    super("app/images/fighter.png")
    self.width = 30
    self.height = 30
    self.clip_width = 15
    self.clip_height = 15
    self.speed = 3.0
    self.remove
    self.tick = 0
    self.check_point = 0
    self.status = nil
    self.pow = 0
    self.level = 1
    self.life = 3
    self.invincible = false
    self.life_gauge = Text.new("Life: #{self.life}", x: 20, y: 15)
  end

  # （move, nutral, opening_action, hit_area, power_up, power_down は変更なし）

  def bloken_by(enemy, enemies)
    return if self.invincible
    self.hit_area.each do |area|
      if enemy.contains?(*area)
        self.life -= 1
        reload_life
        enemy.remove
        enemies.delete(enemy)
        self.invincible = true
        self.check_point = 0
        break
      end
    end
  end

  def update_invincible
    return unless self.invincible
    self.check_point += 1
    self.color.opacity = self.check_point % 10 < 5 ? 0.3 : 1.0
    if self.check_point >= INVINCIBLE_DURATION
      self.invincible = false
      self.color.opacity = 1.0
    end
  end

  # （private メソッドは変更なし）
end
```

`return if self.invincible` で無敵中は判定をスキップします。`INVINCIBLE_DURATION = 120` は約2秒（60fps×2）です。

### app/main.rb で update_invincible を呼び出す

update do の `:start` ブロックに追加します。

app/main.rb

```ruby
when :start
  fighter.opening_action
  fighter.update_invincible
  Bullet.move(bullets, enemies, burns, items)
  items.each { |item| item.move }
  items.each { |item| item.touch(fighter, items) }
  enemies << Enemy1.new if tick % 20 == 0 && rand(0..2) == 0
  enemies.each do |enemy|
    enemy.move(enemies)
    fighter.bloken_by(enemy, enemies)
  end
  Burn.selected_delete(burns)
```

### ファイルの実行

```bash
shooting $ bundle exec rake
```

### 結果

敵に当たると自機が点滅し、約2秒間は再び当たってもライフが減らない。

#### *ここで試したいこと

- `INVINCIBLE_DURATION` を変えて無敵時間の長さを変えてみよう。
- `check_point % 10` の数字を変えて点滅の速さを変えてみよう。
