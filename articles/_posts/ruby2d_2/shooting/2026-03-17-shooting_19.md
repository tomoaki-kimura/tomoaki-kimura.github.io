### Status にスコアを追加する

app/status.rb

```ruby
class Status
  attr_reader :game_status, :score

  def initialize
    @score = 0
    @score_display = Text.new("Score: 0", x: 20, y: 40, size: 20)
    to_title
  end

  def to_title
    @game_status = :title
  end

  def to_start
    @game_status = :start
  end

  def to_game_over
    @game_status = :game_over
  end

  def add_score(points)
    @score += points
    @score_display.remove
    @score_display = Text.new("Score: #{@score}", x: 20, y: 40, size: 20)
  end

  def reset_score
    @score = 0
    @score_display.remove
    @score_display = Text.new("Score: 0", x: 20, y: 40, size: 20)
  end
end
```

### Bullet#hit にスコア加算を追加する

`@status` を `Bullet.move` に渡します。

app/models/bullet.rb（`self.move` と `hit` の引数を更新）

```ruby
def self.move(bullets, enemies, burns, items, status)
  bullets.each do |bullet|
    r = (bullet.angle + 90) * PI / 180
    bullet.x += cos(r) * bullet.speed
    bullet.y -= sin(r) * bullet.speed
    bullet.hit(enemies, bullets, burns, items, status)
  end
end

def hit(enemies, bullets, burns, items, status)
  enemies.each do |enemy|
    if enemy.contains?(self.x, self.y)
      burns << Burn.new(enemy.x + enemy.width / 2, enemy.y + enemy.height / 2)
      ItemPow.set([enemy.x, enemy.y], items) if rand(0..3) == 0
      status.add_score(enemy.class::SCORE)
      enemy.remove
      enemies.delete(enemy)
      self.remove
      bullets.delete(self)
      break
    end
  end
end
```

`enemy.class::SCORE` で、その敵クラスに定義した定数を取得します。

### app/main.rb を更新する

`Bullet.move` に `@status` を追加し、リスタート時に `reset_score` を呼びます。

```ruby
Bullet.move(bullets, enemies, burns, items, @status)
```

リスタートの `r` キー処理に追加：

```ruby
@status.reset_score
```
